# 무료 출처. 무엇을 주고, 날짜 있는 사실

last-verified: 2026-11-18 · ttl-days: 90 · refresh: 네이버 스마트플레이스 도움말, 카카오맵 매장 검색, 네이버 검색광고 도움말, developers.google.com/maps/billing-and-pricing/pricing 과 places 정책 페이지를 보고 무료 한도와 저장 규칙이 바뀌었으면 해당 줄만 고치고 last-verified를 올린다.

2단계에서 읽고, Places API를 쓰기 전에 다시 읽어요. 기본 경로는 네이버 검색과 플레이스·카카오맵을 손으로 보는 것이에요. `places_search.py`는 선택인 구글 Places 도우미이고, 네이버를 조회하지 않아요.

## 한국에서 자주 열리는 조회 (2026-11-18 기준, 페이지는 바뀜)

- 가스시설 시공 업체는 한국가스안전공사 조회에서 이름이 나오는 경우가 있어요. 조회가 기대와 다르면 건너뛰고 메모에 적어요. 전체 설비 업체의 센서스라고 말하지 않아요.
- 홈페이지 하단의 상호, 대표자, 사업자등록번호, 주소는 공개된 사업자 정보예요. 대표를 찾을 때는 `/pitch-the-fix`가 이어서 써요.
- 국세청 사업자상태조회는 번호의 상태이지, 대표자 명단이 아니에요. 대표 이름으로 쓰지 않아요.

다른 업종은 그 업종의 협회와 지자체 등록을 찾아요. 없는 명부를 있다고 하지 않아요.

## 구글 Places API (New). 선택할 때만

이 숫자는 2026-11-13 가격표에서 옮긴 것이에요. 큰 실행 전에 가격 페이지를 다시 봐요. 이 파일의 last-verified는 무료 경로를 네이버 손 확인으로 바꾼 날이에요.

- **SKU별 월 무료 한도** (구글 지도 플랫폼 가격표). Text Search Essentials(ID만) 무제한. Text Search Pro 5,000. Text Search Enterprise 1,000. Place Details Essentials 10,000. Pro 5,000. Enterprise 1,000. Enterprise + Atmosphere 1,000.
- **어느 칸이 어느 등급** (data fields). 별점, 리뷰 수, 웹사이트, 전화는 Enterprise. 표시 이름, 영업 상태, 지도 링크는 Pro. 리뷰 본문은 Enterprise + Atmosphere.
- `places_search.py`는 텍스트 검색에서 Enterprise 칸을 요청해요. 최대 20건인 페이지 하나가 월 1,000건 무료 Text Search Enterprise에 집계돼요. 말 세 개에 페이지 세 개면 칸당 요청 9번.
- **리뷰.** 장소당 최대 5개, 관련순. 리뷰 객체에 사장님 답글 칸이 없어요. 속도와 안 단 답글은 손 확인.
- **저장.** place ID는 캐시 제한의 예외라 계속 저장할 수 있어요. 위도·경도는 최대 30일. 정책은 지도 내용을 서비스 밖으로 내보내거나 스크랩하지 말라고 해요. 다른 칸은 이번 실행의 스냅샷으로 보고, 새 숫자가 필요하면 place ID로 다시 가져와요.
- **표시.** Places 데이터나 리뷰를 보여 줄 때 Google Maps를 밝히고, 리뷰를 보여 줄 때 작성자를 밝혀요. 네이버에서 손으로 본 숫자와 한 칸에 섞지 않아요.

## 공짜처럼 보여도 쓸 가치가 없는 것

- **지도 스크래핑.** 클라우드 스크래퍼나 브라우저 봇. 약관을 깨고, 자주 깨지고, 순위가 필요한 칸은 위의 손 확인이 줘요.
- **업체 명단을 사는 것.** "대구 설비" 같은 산 목록에는 이름이 있어요. 순위에 쓰는 칸(첫 화면, 광고 약속, 답글)은 없어요. 결국 3단계와 4단계를 해요.
