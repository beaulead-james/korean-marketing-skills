# 글 기교. 일곱 규칙과 티

세션의 첫 초안 전과 첫 점수 전에 불러옵니다. 아래 예시는 이 파일을 위해 만들었습니다. 소프트웨어를 만든 사람, 크리에이터나 대행, 지역 가게를 돌아갑니다. 예시 가게는 한빛설비(대구)와 북산일정(다지점 일정)입니다. 실재하지 않습니다. 숫자는 예시입니다.

## 일곱 규칙

### 1. 요청당 끝난 글 하나

만든 사람이 "새 예약 페이지에 대한 글"을 청합니다. 약한 전달은 초안 다섯과 2주 계획입니다. 고르는 일을 물은 사람에게 돌려줍니다. 강한 전달은 끝난 글 하나와 그 아래 한 줄. "차점. 설정을 걷는 방법 드롭. 원하면 씁니다."

계획, 시리즈, 변형은 사용자가 물을 때. 주간 모드처럼.

### 2. 저장할 것

한 글자 전에 "누가 이 글에 다시 오나?"

- **지역.** 지붕 회사가 장마를 올리고 싶어 합니다. 의견. "장마입니다. 지붕을 준비하세요." 아무도 저장 안 합니다. 저장. 우박 뒤, 누구에게 전화하기 전에 찍을 사진 네 장. 짧은 번호 목록.
- **소프트웨어.** 만든 사람이 요금을 바꿨습니다. 의견은 사용량 요금이 왜 공정한지 논합니다. 저장은 옛 요금 페이지와 새 페이지를 나란히, 그리고 손님에게 보낸 메일 그대로. 다른 만든 사람이 베낍니다. 북산일정이면 지점 수 제한이 바뀐 화면.
- **크리에이터.** 영상 편집자의 갈고리 의견. 저장은 최근 영상 20개에서 10초를 넘게 잡은 첫 문장 셋과 유지 그래프.

원본에 쓸 부분이 없으면 이미 가진 사실로 만듭니다. 절차를 번호 단계로, 진짜 가격 설명, 손님이 가장 많이 묻는 질문. 진짜로 아무것도 없을 때만 묻습니다. 의견을 쓰고 잘되기를 바라지 않습니다.

### 3. 영수증보다 먼저 도구

대행이 여섯 고객의 리뷰 요청 문자를 시험했고 짧은 쪽이 이겼다고 올리고 싶어 합니다. 문자 자체로 엽니다.

```
일이 끝난 날 보내세요.
"[이름]님, 오늘 와 주셔서 감사합니다. 괜찮으셨다면
네이버 영수증 리뷰가 작은 가게에 큰 도움이 됩니다. [링크]"
```

여섯 고객 시험은 다음 주 글입니다. "우리가 시험했습니다"로 열면 쓸 부분까지 기다리게 합니다. 가짜 리뷰나 별점 리워드는 문장에 넣지 않습니다.

나눠 주는 것은 작동해야 합니다. 문자를 자기 폰에 보냅니다. 프롬프트는 그것이 이름 붙인 모델에서 돌립니다. 설정은 실제 계정에서 눌러 봅니다.

### 4. 평이한 첫 줄, 그다음 할 일

- **크리에이터.** "유튜브는 영상 하나에 썸네일을 세 개까지 시험할 수 있습니다." 둘째 줄. "다음 다섯 업로드에 탈락한 둘을 B와 C로 넣고 고르게 두세요." 더 재치 있는 첫 줄("썸네일이 거짓말하고 있습니다")은 해독을 요구하고 평이한 줄에 집니다.
- **지역.** "대부분 설비 플레이스는 서비스에 '설비'만 적혀 있습니다." 둘째 줄. "손님이 검색하는 말로 많이 하는 일 열 개를 넣으세요."

첫 줄은 무슨 일이 있었거나 무엇이 참인지. 둘째는 읽는 사람이 할 일.

### 5. 디자인 이미지보다 실제 화면

- **대행.** 광고는 당일을 약속하는데 페이지는 그 말이 없는 가게. 휴대폰의 실제 페이지, 빠진 줄을 동그라미, 상호는 가림. 디자인한 "광고 대 페이지" 그래픽보다 낫습니다. 내 가게가 아니면 가립니다.
- **소프트웨어.** 변경 기록의 한 줄이나 문서 문단을 표시. 브랜드 발표 카드보다 낫습니다.

화면이 영수증입니다. 규칙 6도 쉬워집니다. 읽는 사람이 확인할 수 있습니다.

### 6. 출처와 같은 말

- 도움말이 링크 있는 글은 "도달이 줄 수 있습니다"라고 하면, 글은 "링크드인이 링크 글을 죽입니다"가 아닙니다.
- 보고가 "가장 빨리 자라는 쪽"이면 글은 "가장 빨리 자람"이 아닙니다.
- 변경 기록이 "베타, 순차 공개"면 글은 "모두에게 열림"이 아닙니다.

넘기기 전에 모든 동사, 최상급, 숫자를 출처와 대조합니다.

### 7. 끝났다는 것은 오늘 올릴 수 있다

마케팅 대행이 런칭 글 다섯을 청합니다. 약한 전달. 글 셋과, `[고객 결과를 넣으세요]`로 가득하고 채우기 전에 경쟁을 45분 조사하라는 쪽지. 사용자는 그걸 올릴 수 없으므로 글이 아니었습니다.

강한 전달. 브리프가 이미 가진 것(하는 일, 가격, 일이 진행되는 방식, 예비 손님이 항상 묻는 질문)으로 쓴 글 다섯. 각각 그대로 올릴 수 있음. 하나에만 줄 안 표시. `[verify: 3일 처리가 아직 맞는지]`. 숫자가 바뀌어도 읽힙니다.

- 확인 표시는 글당 최대 하나, 없는 편이 낫습니다.
- 빈칸 없음, "여기에 X", 글이 나가기 전에 조사 숙제 없음.
- 전달에 점수, 원형 라벨, 루브릭 메모 없음. 끝의 한 줄이 무엇으로 만들었는지를 말할 수 있습니다.

## 티

서로 다른 티마다 점수에서 5점(최대 25). 소리 내어 읽고, 슬로건처럼 들리면 다시 씁니다. 패턴이 정확한 단어보다 중요합니다.

| 티 | 있음 | 나은 것 |
|---|---|---|
| 균형 쌍 | "광고가 클릭을 얻고, 페이지가 전화를 얻습니다." | "광고는 됐습니다. 연 페이지에 번호가 없었습니다." |
| "X는 새로운 Y" | "플레이스가 새로운 홈페이지입니다." | "지난달 플레이스를 본 사람이 사이트보다 많았습니다. 1,900 대 240." |
| 쌓인 조각 | "전화 없음. 문자 없음. 예약 없음." | "아무도 다시 전화하지 않아서, 다음 업체를 예약했습니다." |
| 반사적 "A가 아닙니다. B입니다" | "이탈은 가격 문제가 아닙니다. 온보딩 문제입니다." | "나간 계정의 대부분은 첫 주에 일정을 연결하지 않았습니다." |
| 문장이 같은 시작 | "필요합니다… 필요합니다… 필요합니다…" | 바꾸거나, 진짜 목록으로 |
| 요약하거나 펀치로 닫기 | "그래서 속도가 이깁니다." | 마지막 구체에서 끝내거나, 멈춤 |
| 연출된 열기 | "콜드메일에 대해 모두가 틀렸습니다." | 발견으로 시작 |
| 요점을 선포 | "이 차트가 런칭이 왜 망했는지 설명합니다." | 차트가 보여 주는 것을 말함 |
| 모두가 이미 믿는 문장 | "손님은 빠른 답을 원합니다." | 놀라운 발견과 그 증거 |
| 공개를 세팅하는 콜론 | "결과. 예약 3배." · "핵심은." | "첫 달 예약이 세 배가 됐습니다." 진짜 목록이나 붙여 넣은 블록 앞의 콜론은 괜찮습니다 |
| 반사적 셋 | "더 빠르고, 더 싸고, 더 좋게." | 참이라서 고른 둘, 또는 넷 |
| 독자에게 숙제 | "응답 시간은요? 재고 있나요? 확인해 볼 만합니다." | 어디서 찾는지 말함 |
| 추상이 보상 | "결국 신뢰입니다." | 숫자, 단계, 그림 |
| 한 출처의 인용 여러 개 | 같은 글의 조각 넷 | 인용 하나. 나머진 화면 |
| 글 안의 작은 글씨 | 요점 뒤 단서 셋 | 단서는 답글. 이야기의 일부인 정직한 한 줄은 괜찮음 |
| 실제 예시가 있는데 가정 | "치과를 상상해 보세요…" | 읽는 사람이 찾을 수 있는 공개 예시 |
| 엠 대시, "새겨 두세요", "핵심은 이겁니다", 과장어(게임 체인저, 잠금 해제, 딜브, 레버리지), "동의?" 닫기, 이모지로 여는 첫 줄, 빈 최상급, 가짜 겸손 | | 평이한 문장 |

영어 직역투도 티입니다. "혁신적인 솔루션", "원스톱", "고객 만족이 최우선".

## 전과 후

소프트웨어를 만든 사람의 초안, 52점.

> 핵심은 이겁니다. 온보딩은 기능 문제가 아닙니다. 초점 문제입니다.
>
> 설정을 9단계에서 3단계로 줄였습니다. 결과는? 활성화가 크게 올랐습니다.
>
> 단순함이 이깁니다. 언제나.

티. "핵심은 이겁니다" (-5), "A가 아닙니다. B입니다" (-5), 공개형 "결과는?" (-5), 펀치로 닫기 (-5). 저장 없음. 베낄 것이 없습니다.

다시 쓴 것, 78점. 숫자는 자격 은행의 진짜를 대신하는 자리입니다.

> 설정을 9단계에서 3단계로 줄였습니다. 뺀 6개는 여기로 갔습니다.
>
> 1. 회사 규모. 나중에, 결제 안에서
> 2. 로고 업로드. 기본은 이니셜
> 3. 동료 초대. 3일째, 첫 예약 뒤로
> 4. 시간대. 브라우저에서 읽음
> 5. 달력 색. 삭제
> 6. 환영 영상. 첫 화면의 예시 예약으로 교체
>
> 첫 주 활성화가 31%에서 47%로 갔습니다.
>
> 설정이 3단계를 넘으면, 각 단계를 적고 대신 어디에 둘 수 있는지 쓰세요.

저장은 목록이고, 영수증(활성화 숫자)보다 앞에 있습니다. 첫 줄은 평이하고, 글은 읽는 사람이 할 수 있는 것에서 끝납니다.
