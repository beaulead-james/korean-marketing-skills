# 설정. 아무것도 없는 상태에서 동작하는 토큰까지

순서가 중요해요. 각 단계의 오류 메시지는 다른 단계의 이름을 말하지 않아요. 순서가 틀리면 오해를 부르는 실패가 나와요.

## 0. 시작 전에 필요한 것

- **메타 비즈니스** (business.facebook.com). 개인 광고 계정만이 아니에요
- 그 비즈니스의 **관리자** 접근. 직원 접근은 시스템 사용자를 만들 수 없어요
- **페이스북 페이지.** 모든 광고는 페이지에서 나가요. 페이지 없는 광고는 없어요
- 광고 계정의 **결제 수단**

이미 광고 관리자로 광고를 하고 있으면 넷이 있어요.

## 1. 앱을 찾거나 만들기

`https://developers.facebook.com/apps/`

앱이 있으면 재사용해요. 새 앱은 자기 게시와 자기 심사가 필요하고, 이득이 없어요.

만들 때 유형은 **비즈니스**. 그다음 앱 대시보드, 설정, 기본, 비즈니스 계정에서 비즈니스에 연결해요.

**앱 ID**를 적어요. 토큰 생성에 필요하고, "비즈니스 설정에 앱이 안 보여요"라고 할 때 확인할 값이에요. 비즈니스에 연결되지 않은 앱은 거기에 나타나지 않아요.

## 2. 앱 게시

앱 대시보드, 설정, 기본. 채울 것.

- **개인정보 처리방침 URL.** 필수, 열려야 함
- **카테고리**
- 위쪽 토글을 **개발**에서 **라이브**로

지금 해요. 나중이 아니에요. 개발 모드는 **광고 소재 생성만** 막아요. 다른 API 호출은 성공해서, 게시 안 된 앱은 긴 스크립트의 맨 끝에서, 캠페인과 광고 세트가 이미 생긴 뒤에 실패해요.

## 3. 시스템 사용자 만들기

`https://business.facebook.com/settings/system-users`

추가. 사람 이름이 아니라 연동 이름으로 (`ads-automation`). 역할은 캠페인 관리면 **직원**으로 충분해요. 연동이 자산이나 다른 사용자를 관리해야 할 때만 **관리자**.

## 4. 시스템 사용자에게 앱 역할

`https://business.facebook.com/settings/apps`

앱 선택, **사람 추가**, 시스템 사용자, **앱 개발**.

**거의 항상 빠지는 단계예요.** 이게 없으면 토큰 생성에 *"사용 가능한 권한 없음"*과 빈 범위 목록만 나오고, 그 화면은 앱 역할이 빠졌다고 말하지 않아요.

## 5. 자산 할당

시스템 사용자로 돌아가 해당 사용자, **자산 할당**.

| 자산 | 권한 | 다른 쪽을 안 주는 이유 |
|---|---|---|
| 광고 계정 | **캠페인 관리** | "광고 계정 관리"는 재무와 사용자 관리까지 줘요. 자동화에 과해요 |
| 페이지 | **광고** | "페이지 관리"는 토큰이 페이지로 게시하게 해요 |
| 픽셀·데이터 세트 | **이벤트 데이터 세트 사용** | `promoted_object`와 CAPI에 필요 |
| 인스타그램 계정 | **광고** | 인스타 게재 위치를 쓸 때만 |

각각 따로 할당해요. 화면은 건너뛴 것을 경고하지 않아요.

## 6. 토큰 생성

시스템 사용자, 해당 사용자, **새 토큰 생성**.

- **앱.** 1단계의 앱
- **만료.** **없음**
- **범위.** `ads_management` (보고도 당기면 `ads_read`. 연동이 자산을 관리할 때만 `business_management`)

바로 복사해요. 한 번만 보여요.

### 저장

저장소가 아니라 환경에.

```bash
export META_ACCESS_TOKEN='...'   # 스크립트는 META_ADS_TOKEN도 받아요
```

**만료 없는 `ads_management` 토큰은 돈을 쓸 수 있는 자격 증명으로 대해요.** 채팅, 로그, 스크린샷, 커밋에 한 번이라도 나오면 폐기하고 다시 만들어요. 시스템 사용자, 해당 사용자, **토큰 폐기**.

## 7. 인스타그램을 광고 계정에 연결

`https://business.facebook.com/settings/instagram-accounts`

계정 선택, **자산 연결**, 광고 계정.

건너뛰면 광고 생성이 *"Ad account has no access to this Instagram account"*로 실패해요. Advantage+ 게재 위치가 기본으로 인스타그램을 포함해서, 인스타에 낼 생각이 없어도 만나요.

## 8. 확인

```bash
node ${CLAUDE_SKILL_DIR}/scripts/preflight.mjs
```

토큰 신원, 부여된 범위, 광고 계정 상태와 통화, 사용 가능한 페이지, 픽셀 접근, 앱이 라이브인지 확인해요. 아무것도 쓰지 않아요. 통화가 KRW이면 예산은 원 단위(오프셋 1)예요.

## 토큰 디버그

`https://developers.facebook.com/tools/debug/accesstoken/`

토큰을 붙여요. 속한 앱, 범위, 만료, 뒤의 사용자 또는 시스템 사용자를 보여요. 호출이 권한 오류를 주면, 네 권한 중 무엇이 빠졌는지 여기가 말해요. 토큰 값을 채팅이나 파일에 다시 적지 않아요.

## 흔한 실패

| 증상 | 원인 |
|---|---|
| 토큰 생성에서 "사용 가능한 권한 없음" | 시스템 사용자에게 앱 역할이 없음 (4단계) |
| `(#200) Requires ads_management permission` | 범위를 안 체크했거나, 환경의 토큰이 다름 |
| `act_...`에 `(#100) Unsupported get request` | 광고 계정이 시스템 사용자에게 없거나, `act_` 접두사가 빠짐 |
| 비즈니스 설정, 앱에 앱이 없음 | 앱이 비즈니스에 연결되지 않음 (1단계) |
| 오늘은 되는데 60일 뒤 실패 | 없음이 아니라 짧은 토큰을 만듦 |
| `Ad account has no access to this Instagram account` | 7단계 |
| `created by an app that is in development mode` | 2단계 |
