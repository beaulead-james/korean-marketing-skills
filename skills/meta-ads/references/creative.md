# 유료 소셜 소재

## 크롭 안전 영역

1080x1920 스토리 애셋은 피드에서 **잘려요**. 레터박스가 아니에요.

| 게재 위치 | 비율 | 1920px 애셋에서 세로로 잘리는 양 |
|---|---|---|
| 스토리·릴스 | 9대16 | 없음 |
| 피드 (세로) | 4대5 | 양 끝에서 약 285px |
| 피드 (정사각) | 1대1 | 양 끝에서 약 420px |

노출의 대부분은 피드예요. 위나 아래 420px 안은 가장 중요한 자리에서 사라져요.

**중요한 요소는 전부 y 420에서 1500 안에** 두고 한 블록으로 움직여요. 식별, 메시지, 행동 요청이 모든 크롭에 남게.

전체 크기 렌더를 믿지 말고 크롭을 시뮬레이션해요.

```js
import sharp from 'sharp';
for (const h of [1350, 1080]) {          // 가로 1080에서 4대5와 1대1
  await sharp(file)
    .extract({ left: 0, top: Math.round((1920 - h) / 2), width: 1080, height: h })
    .toFile(`crop_${h}.jpg`);
}
```

그다음 광고 관리자에서 게재 위치별 미리보기를 봐요. 실제로 그려요. 시뮬레이션이 놓친 것을 잡아요.

## 디자인처럼 보이지 않게

디자인처럼 보이는 소재는 광고로 읽히고 스크롤을 지나쳐요. 사람처럼 읽히는 것.

- **줄마다 둥근 자막 상자.** 평평한 띠 하나가 아니에요. 줄별 알약은 인스타·릴스 자막의 형태이고, 띠 하나는 슬라이드처럼 보여요.
- **시스템 산세리프의 굵은 이탤릭.** 브랜드 전용 서체가 아니에요. 기운 글자는 그 플랫폼의 기본 글자처럼 읽혀요.
- **실제 작업 사진.** 업종 사람이 보는 카테고리에서는 실제 현장 사진 한 장이 스톡보다 더 "우리 일"로 보여요. 네이버 영수증 리뷰 문장을 카드에 쓸 때는 원문만, 별점은 리뷰에 별이 있을 때만.
- **가짜 플랫폼 크롬 금지.** 진행 막대, 답글 상자, 위로 밀기 화살표, 그려 넣은 커서는 메타 UI를 흉내 낸 것으로 거절돼요. 평범한 자막 띠는 괜찮아요.

**문안 길이를 믿지 말고 자동으로 맞추세요.** SVG는 사각형을 자기 글자에 맞출 수 없고 측정 API가 없으니, 진행 폭을 추정하고 들어갈 때까지 줄여요. 이탤릭은 진행 폭 밖으로 삐져요. 이탤릭이면 좌우 여백을 더 줘요. 잘린 줄은 돈이 나간 뒤에야 눈에 띄는 결함이에요.

## 특수 광고 카테고리

주택(`HOUSING`), 채용(`EMPLOYMENT`), 신용·금융상품(`FINANCIAL_PRODUCTS_SERVICES`. 2025년 1월에 Credit를 대체), 사회 이슈·선거. 일자리, 집, 대출이나 다른 금융 상품 광고면 선언이 필요할 수 있어요. 메타가 타겟을 걷어내요. 국가 범위는 `meta-facts.md`예요. 한국만 대상이면 제한에 들어갈지 선택할 수 있어요.

제한이 켜지면.

- 연령·성별 타겟 없음 (18~65+, 모든 성별)
- 세부 관심사·행동 타겟 없음
- 위치 반경 최소. 미국·캐나다 15마일 또는 25km, 유럽 15km
- 유사 타겟 제한

**결과. 제한이 켜진 캠페인에서는 소재가 타겟이에요.** 관심사 타겟이 없으면, 맞는 사람이 자신을 알아보는 것은 광고뿐이에요. 오디언스 식별을 이미지에 말로 넣어요 (`대구 설비 기사`). 영리한 후크로 대체하지 않아요. 그 줄이 크롭에서 살아남는지 확인해요. 피드에서 사라지면 남은 타겟이 없어요.

채용과 금융 상품은 수입 주장을 금해요. 문안을 고칠 수 있는 곳마다 코드로 막고, 실패는 크게 알려요.

```js
const MONEY = /월급|연봉|시급|순수익|월\s?\d+\s?만|\d+\s?억|\$\s?\d|\b\d+\s?(k|dollars|usd)\b|\bper hour\b|\/hr\b/i;
```

카테고리는 **캠페인 생성 뒤 바꾸기 어려워요.** 잘못되면 지우고 다시 만들어요.

표시광고법. 거짓·과장, 기만, 부당 비교는 넣지 않아요. 채용 급여, 대출 금리, 부동산 수익을 단정하기 전에 업종 심의를 확인하라고 경고만 해요. 조문 번호는 단정하지 않아요.

## Advantage+ 크리에이티브 보정

메타는 기본으로 이미지를 자동 크롭하고, 자기 글자를 올리고, 밝기를 조정하고, 변형을 만들어요. 구성이 하중을 받으면(안전 영역이 있으면 그래요) 이것이 망쳐요.

API 필드 `standard_enhancements`는 폐기됐고 기능별 대체는 움직여요. **광고 관리자에서 설정**하고 API로 확인해요.

```
GET /[CREATIVE_ID]?fields=degrees_of_freedom_spec
→ advantage_plus_creative: OPT_OUT
```

## 문안 구조

```
message      이미지 위 본문. "더 보기" 전 약 125자가 보임
name         제목. 이미지 아래 굵게
description  제목 아래 작은 줄. 모바일에서 자주 잘림
```

메시지를 앞에 두세요. 접힌 뒤는 이미 관심 있는 사람용이에요. 가격은 원, 첫 줄에 하는 일과 지역, 버튼은 전화·카카오·예약 중 랜딩이 실제로 하는 일.

## 변형 시험

크리에이티브 여러 개를 **광고 세트 하나**에 두세요. 세트마다 하나면 예산이 갈라지고 각자 데이터의 일부로 배워요. 세트 하나면 메타가 공유된 학습 위에서 소재 사이에 예산을 나눠요.

`utm_content`에 변형 이름을 넣어, 광고 관리자만이 아니라 자기 분석에서도 귀속되게 해요.
