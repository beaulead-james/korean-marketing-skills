# 지역 질문 세트와 손 캡처

/ai-search 지역 가지의 1단계 전에 읽으세요. 예시 업체는 한빛설비 (대구, 설비)입니다. 숫자와 경쟁 자리는 예시입니다.

## 지역 질문 세트의 규칙

- **모든 질문이 장소를 부릅니다.** 시, 또는 큰 도시의 구·동. 엔진이 사용자 위치를 짐작한 것은 측정이 아닙니다.
- **세트마다 도시 하나.** 다섯 구에 나가는 사업은 본거지 구의 세트 하나와, 아래 범위 드릴로 나머지를 봅니다.
- **10개에서 15개.** 원문 그대로 고정. MONITOR는 이 질문을 그대로 반복합니다.
- **손님의 말이 먼저.** 통화 메모, 문자, 리뷰, `voc.md`에서 말투를 꺼낸 뒤에 지어내세요.

## 여섯 종류, 예시 업체

| 종류 | 틀 | 예시 |
|---|---|---|
| 범주 | 〈도시·구〉 〈서비스〉 추천 | "대구 수성구 보일러 업체", "대구에서 믿을 만한 설비" |
| 긴급 | 〈구〉 〈증상〉 지금 | "수성구 보일러 지금 나와 주는 곳", "달서구 동파 오늘 밤" |
| 문제 | 〈증상〉, 〈구〉에서 누가 보나 | "보일러 밑에서 물, 대구에서 오늘 봐 주는 곳" |
| 비용 | 〈작업〉 비용 〈도시〉 | "대구 보일러 교체 비용" |
| 비교 | 〈업체〉 대 〈경쟁〉 / 〈구〉 〈경쟁〉 대안 | "한빛설비 대 〈경쟁〉", "수성구에서 〈경쟁〉 같은 설비" |
| 브랜드 | 〈업체〉 후기 / 어떤가 | "한빛설비 대구 후기", "한빛설비 믿을 만해" |

기본 혼합. 범주 3, 긴급 2, 문제 3, 비용 2, 비교 1에서 2, 브랜드 2.

미국 도시 이름, "near me"만으로 된 영어 질문, Ask Maps 전용 질문은 기본 세트에 넣지 마세요. Ask Maps는 미국·인도 기능입니다. 구글·외국인 손님이 목표일 때만 더하세요.

## 손으로 캡처

엔진은 무료 API로 답을 공유하지 않으므로, 가장 정직한 캡처는 사람(또는 브라우저를 쥔 에이전트)이 질문하고 답을 붙이는 것입니다.

| 표면 | 방법 | 기록 |
|---|---|---|
| 네이버 통합검색 | 시·구가 박힌 질문. Cue:와 AI 브리핑이 있으면 그 본문 | 답, 출처, 불린 업체 순서. 브리핑이 없으면 없다고 기록 |
| 네이버 플레이스 | 업체명과 업종+구 검색 | 소개, 전화, 시간, 리뷰가 답과 다른 곳 |
| 카카오맵 | 같은 업종 검색 | 등록 정보가 네이버와 다른지 |
| 챗GPT | 새 채팅, 검색 켬, 로그인 여부 기록 | 답 전문, 출처, 불린 순서 |
| 퍼플렉시티 | 새 스레드 | 답, 번호 달린 출처 |
| 제미나이 | 새 채팅 | 답, 출처나 지도 결과 |
| 구글 AI Overview / AI Mode | 구글 유입이 있을 때. 지역을 그 도시로 | 개요 본문, 인용 출처 |
| Ask Maps | 미국·인도에서만, 그 도시 근처의 휴대폰 | 추천 업체와 각각의 이유. 한국 기본 아님 |

상위 질문은 다른 날이나 새 세션에서 두 번 캡처한 뒤에 안정이라고 부르세요. 다시 치는 것보다 화면이 낫습니다.

## 기록 표 (답마다 한 행, 노트 파일)

`날짜 | 엔진 | 장소 | 질문 원문 | 불린 업체 순서 | 상태 (CITED / MENTIONED / ABSENT / NOT OBSERVED) | 인용 출처 | 틀린 사실`

## 틀린 사실 점검

업체를 부르는 답마다 사실, 스마트플레이스, 카카오맵과 대조하세요.

| 항목 | 흔한 틀린 답 | 보통 나오는 곳 |
|---|---|---|
| 전화 | 옛 번호, 또는 다른 업체 이름 아래의 이 번호 | 오래된 디렉터리, 복제 사이트, 소개 글에 남은 옛 번호 |
| 위치·출장 | 틀린 구, 없는 매장 | 옛 등록, 이전 주소 |
| 시간 | 하지 않는 "24시간", 또는 여는데 휴무 | 플레이스, 옛 등록, 사이트의 낡은 페이지 |
| 서비스 | 안 하는 일, 또는 대표 서비스 누락 | 얇은 서비스 페이지, 업종 카테고리 |
| 가격 | 지어낸 값, 전국 평균을 그 업체 가격처럼 | 엔진이 빈칸을 채움, 낡은 페이지 |
| 상호 | 다른 지역의 비슷한 이름과 합쳐짐 | 도시 사이의 이름 충돌 |

틀린 사실마다 있을 법한 출처를 적어 지역 수정 L1이 됩니다.

가격을 답에 받아 적을 때는 예시인지 장부인지 구분하세요. 통화는 원입니다. "최저", "대구 1위" 같은 표현은 표시·광고법의 거짓·과장과 부당 비교에 걸립니다. 글에 넣기 전에 경고하세요.

## 범위 드릴 (선택, 여러 구)

본거지에서는 있는데 다른 구도 중요하면, 사업이 실제로 나가는 구 2개에서 4개에 더 작은 세트(범주와 긴급 3개에서 4개)를 돌리세요. 존재가 어디서 끊기는지, 각 구를 누가 가지는지가 나옵니다. 나가지 않는 구에서 멈추세요. 나가지 않는 구의 드릴은 쓸 수 있는 것을 재지 않습니다. 한빛설비 예시라면 수성구가 본거지일 때 달서구·중구만, 실제로 출장이 있을 때만.
