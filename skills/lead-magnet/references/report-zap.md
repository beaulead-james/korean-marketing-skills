# 자동화 예시. 무료 보고서

마그넷이 메일이나 카카오로 전달되는 개인 보고서일 때("사이트를 보내면 무료 점검을 받습니다"), 또는 사람 없이 돌아가는 마그넷을 원할 때 불러옵니다. 예시는 지역 가게를 돕는 대행이나 프리랜서입니다. 사장님이 사이트와 연락처를 넣으면 몇 분 뒤 짧고 구체적인 사이트 보고를 받습니다. 같은 모양은 "데이터가 들어가면 보고가 나가는" 마그넷 어디에나 됩니다.

자동으로 라이브 발송하지 않습니다. 테스트 한 번과 사장님의 확인 뒤에 켭니다. 긁어온 명단에 보내지 않습니다.

## 네 단계

1. **트리거. 새 폼 항목이나 시트 행.** Zapier로 들어가는 폼이면 됩니다. 구글 폼, 탈리, 대행 사이트의 폼, Zapier Interfaces, 또는 구글 시트 새 행. 보고에 필요한 것만. 웹사이트, 전화 또는 카카오를 받을 연락처, 이름, 업종, 도시. 메일은 보고서를 메일로 줄 때만. 개인정보 동의 문구를 폼에.
2. **상대 사이트를 읽는다.** 웹 읽기 단계가 페이지 글을 가져옵니다. Zapier 내장, 또는 웹훅의 스크레이프 API. 짧은 보고에는 홈으로 충분합니다. 스크립트가 무거운 사이트는 글이 거의 안 나오므로, 프롬프트가 "많이 못 읽음"을 처리해야 합니다.
3. **AI가 HTML 보고서를 쓴다.** Zapier의 AI, 또는 OpenAI·Anthropic 단계가 페이지 글에서 메일·카카오에 넣을 본문 하나를 씁니다.
4. **전달.** 메일(Gmail, Outlook, 트랜잭션 메일) 또는 사장님이 확인한 카카오·문자 경로. 본문은 3단계, 받는 사람은 1단계. 광고성 후속이 아니면, 요청한 보고 자체는 그들이 신청한 응답입니다. 그 뒤의 영업 문자는 (광고), 보내는 이, 수신거부, 21시~08시 별도 동의. 정보통신망법의 광고성 정보. 조문 번호는 단정하지 않습니다.

## 프롬프트, 이 순서

```
[2단계의 사이트 글 필드, 먼저]

출력 형식 (그대로):
- HTML 본문 하나만. 마크다운, 코드 펜스, 해설 없음.
- 인라인 스타일만. 최대 너비 600px. 배경 #FFFFFF, 글자 #1A1A1A, 강조 #____.
- 400단어 미만.

일:
{이름}의 {도시} {업종} 사이트를, 손님이 휴대폰으로 보듯 검토합니다. 짧은 보고:
1. 페이지에서 인용해, 잘한 것 한 문장.
2. 전화를 늘릴 가능성이 큰 변경 셋, 중요한 순. 각각 본 것(인용), 왜 전화가 줄어드는지, 고침 한 문장.
3. 다음 하나. 이 메일에 답하면 고침을 진행합니다.

규칙:
- 위 페이지 글에 있는 것만. 안 보이면(번호 없음, 가격 없음) 추측하지 말고 "찾지 못했습니다"라고.
- 페이지에 없는 통계 없음. 지어낸 경쟁 없음.
- 글이 거의 비었으면 사이트를 못 읽었다고 말하고 수동 검토를 제안.
```

TASK 블록 안의 검토 방법이 전문이 사는 곳입니다. `/first-screen-check`의 목록이나 대행 자신의 진단표를 넣습니다.

## 만들며 배운 것

- **형식 규칙이 긴 지시보다 앞입니다.** 긴 방법 블록이 먼저면, 모델이 방법 자신의 출력 형식을 따르고 끝에 둔 HTML 지시를 무시했습니다.
- **색을 이름 붙입니다.** 헥스가 없으면 첫 패스가 자기 팔레트를 골랐습니다.
- **자동으로 생긴 출력 필드를 지웁니다.** Zapier가 프롬프트에서 출력 필드를 여러 개 추론할 수 있습니다. 메일 본문에 HTML 하나가 필요하면 지웁니다.
- **프롬프트 길이를 봅니다.** AI by Zapier 프롬프트가 저장 시 50,000자에서 조용히 잘린 것을 2026년 9월에 봤습니다. 사이트 필드를 먼저 두고, 한도를 한참 밑으로.
- **감사 페이지의 기다림을 맞춥니다.** 라이브는 약 3~4분, 편집기 미리보기는 약 8분이었습니다. "약 5분 안에 도착합니다"가 정직했습니다. 그 시간은 그 관찰이지 모든 계정의 보장이 아닙니다. 자기 테스트로 확인합니다.
- **켜기 전에 실제 사이트로** AI 단계의 미리보기를 돌립니다.
- **비용을 셉니다.** 실행마다 Zapier 작업 여러 개와 AI 단계. 유료 트래픽을 보내기 전에 요금제를 봅니다.

## 변형

- **산출물 둘.** 다섯 번째 단계. AI가 가게 브랜드의 전달용 자산도 씁니다. 예. 냉방 회사의 "집 설비 12항목 점검". 두 번째 전달이 그것을 보냅니다. 사장님은 자기 손님에게 줄 것이 생기고, 대행은 후속 이유가 생깁니다.
- **지역 가게 자신의 버전.** 집 주인이 주소, 기기 나이, 사진을 넣습니다. 보고는 수리·교체 판독과 사장님 규칙의 가격 범위입니다.

## 배포

폼을 약속 하나의 페이지에 둡니다. "사이트 무료 3가지 점검, 5분 안에." 답은 사람에게 라우팅합니다. 후속은 `/email-sequences`. 보고의 다음은 답장이나 통화 예약이고, 답 없는 사람에게 짧은 후속. 야간 발송 없음.

사람이 직접 넣은 사이트에만 돌립니다. 긁은 목록에 돌려 결과를 보내는 것은 콜드 연락이고, 그 규칙은 `/pitch-the-fix`입니다. 상호와 이름, 과장된 성과 약속 없음, 고칠 문제 하나.

## 만드는 법

결과가 비슷한 두 길.

- **Zapier 편집기에서 손으로.** 여러 단계 Zap을 만들어 본 사람에게 곧게.
- **Make나 n8n**에 같은 모양. 트리거, HTTP로 가져오기, LLM 호출, 전달.
