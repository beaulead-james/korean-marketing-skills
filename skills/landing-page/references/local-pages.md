# 지역 서비스 페이지

**지역 오퍼가 페이지 종류(전화 우선, 예약, 견적)를 고른 뒤 `architecture.md`를 쓰기 전에 불러옵니다.** 종류별 섹션, 감사 페이지, 지역 페이지에서 중요한 빌드, 예시가 있습니다. 스킬 본문의 나머지(섹션당 일 하나, 증거 위치, 마찰, 빌드 참조)는 그대로 적용됩니다.

## 섹션 스택

각 스택은 기본입니다. 삭제 테스트로 자르고, 더할 때는 이유가 있어야 합니다.

**전화 우선** (급한 일)

| # | 섹션 | 일 하나 |
|---|---|---|
| 1 | 얇은 헤더. 로고, 번호가 탭 전화 버튼 | 글을 읽기 전에 전화하게 한다 |
| 2 | 히어로. 약속 헤드라인(광고의 말), 하는 일+지역, 증거 한 줄, 전화 버튼, 카카오 채널 링크 | 맞는 곳임을 확인하고 전화를 받는다 |
| 3 | 오늘 고치는 일 | 손님 말로 문제를 찾게 한다. "온수기 누수", "뜨거운 물이 안 나와요" |
| 4 | 어떻게 진행되나 | 전화, 기사 출발, 작업 전 가격, 수리, 정리. 얼마 나올지 모르는 두려움을 뺀다 |
| 5 | 가격, 정직하게 | 출장비, 견적 방식, 할부가 진짜일 때만 할부 |
| 6 | 최근 리뷰 | 네이버 영수증 리뷰 3~5개, 최근, 이름. 플레이스로 링크. 가짜 리뷰는 쓰지 않는다 |
| 7 | 가는 지역 | 구·동. "우리 동네 오나요"에 답한다 |
| 8 | FAQ | 가격, 시간, 보증, 면허의 실제 답 |
| 9 | 닫는 전화 버튼, 그리고 내내 고정 전화 막대 | 스크롤한 사람을 받는다 |

**예약 페이지** (일상 일)

구·동 또는 주소가 먼저입니다. 지역을 거르고 손님이 한 걸음 들어옵니다. 그다음 서비스, 시간, 연락처. 첫 화면은 약속 헤드라인, 증거 한 줄, 구·동 필드입니다. 정액이면 가격을 앞에 보여 줍니다. "배수 청소, 15만 원". 전화하고 싶은 사람을 위해 번호는 계속 보입니다. 카카오 예약이나 네이버 예약이 이미 있으면 그 버튼을 새로 만든 폼보다 앞에 둡니다.

**견적 페이지** (큰 일)

결과와 견적에 대한 약속 헤드라인("대구 지붕 무료 점검. 발견한 것을 사진으로"), 무거운 증거(경력, 면허, 보증, 끝난 일의 사진), 견적 방문에서 일어나는 일, 할부가 진짜일 때만 할부, 그다음 짧은 폼. 이름, 전화, 주소, 일에 대한 질문 하나. 전형적 일의 실제 가격 범위는 여기서 도움이 됩니다. 지어낸 범위는 해를 끼칩니다. 아래를 봅니다.

## 감사 페이지

폼이나 예약 뒤에 손님은 됐나 궁금해하고 계속 비교합니다. 페이지는 다음에 무엇이 언제 일어나는지 확인합니다. "한빛에서 15분 안에 전화드립니다. 오전 7시~오후 7시. 그 외 시간은 다음 날 아침 첫 통화." 지금 걸고 싶은 사람을 위해 번호를 보여 주고, 카카오 채널이 있으면 그 버튼도 둡니다. 준비할 것(누수 사진, 모델명)을 적습니다. 두 번째 오퍼도, 뉴스레터 신청도 없습니다.

## 지역 페이지 빌드에서 중요한 것

빌드 기준은 `references/landing-page-build.md`입니다. 여기에 더합니다.

- **번호가 나오는 곳마다 탭 전화.** 예시 번호입니다.

```html
<a href="tel:+82530000199">053-000-0199</a>
```

링크의 숫자와 보이는 숫자가 같거나, 콜트래킹 도구가 둘 다 바꿉니다.

- **휴대폰 고정 전화 막대.** 데스크톱에서는 숨깁니다.

```html
<a class="callbar" href="tel:+82530000199" data-cta="callbar">전화 053-000-0199</a>
<style>
  .callbar { position: fixed; left: 0; right: 0; bottom: 0; padding: 14px; text-align: center;
             background: var(--accent); color: #fff; font-weight: 700; z-index: 50; }
  @media (min-width: 720px) { .callbar { display: none; } }
  body { padding-bottom: 56px; }
</style>
```

- **전화 탭을 버튼 클릭처럼 표시** (`data-cta="callbar|hero|closing"`). 분석 스텁이 위치별 전화 탭을 셀 수 있습니다. 구글 광고가 있으면 `/google-ads-tracking`이 광고 집계를 맞춥니다. 네이버 검색광고는 광고주 센터의 전환으로 같은 일을 합니다.
- **카카오 채널 버튼**은 채널의 공개 추가 URL로 연결합니다. 개인 카카오톡 ID를 본문에 뿌리지 않습니다.
- **구조화 데이터는 정직하게.** `LocalBusiness` 하나(또는 `Plumber`, `Dentist` 같은 업종)에 실제 상호, 주소나 서비스 지역, 전화, 영업시간. `aggregateRating`을 박지 않습니다. 구글은 업체가 자기 리뷰를 마크업한 별점을 무시하고, 플레이스와 어긋난 "5.0"은 페이지 위의 거짓말입니다. 사람에게는 지금 별점을 글자로 보여 줍니다.
- **FAQ 가격은 진짜이거나 없습니다.** FAQ 글과 JSON-LD를 AI 답변이 인용합니다. 지어낸 범위가 손님이 기대하는 가격이 됩니다. 표시광고법의 거짓·과장입니다.
- **스톡보다 실제 사진.** 차량, 기사, 끝난 일. 깨끗한 유니폼의 웃는 모델은 바로 들킵니다.
- **번호를 받는 폼**에는 수집 항목, 목적, 보유 기간, 동의를 적습니다. 개인정보보호법. 조문 번호는 단정하지 않습니다.

## 예시 (한빛설비, 대구)

한빛설비는 예시 가게이고 실재하지 않습니다. 네이버 검색광고에 광고 그룹이 셋 있습니다. 가격과 별점은 예시입니다.

| 광고 그룹 | 광고 약속 (그대로) | 페이지 | 헤드라인 |
|---|---|---|---|
| 긴급 | "대구 누수, 당일 출동. 견적은 작업 전에 글로." | 전화 우선 | "대구 누수, 당일 출동합니다. 견적은 작업 전에 글로 드립니다." |
| 배수 | "배수 청소 15만 원. 오늘 예약." | 예약 | "대구 배수 청소, 15만 원. 오늘 예약하세요." |
| 온수기 | "온수기 견적 무료. 다음 날 설치." | 견적 | "온수기 견적 무료. 대구에서 다음 날 설치합니다." |

이전에는 셋 다 홈으로 갔고, 첫 화면은 "1998년부터 믿음의 설비"였습니다. 세 약속 중 아무것도 없었습니다. 이후 광고 그룹마다 자기 페이지가 열리고, 헤드라인은 광고의 말을 반복하며, 증거 한 줄은 같은 진실입니다. "네이버 별점 4.8, 리뷰 312. 면허·보험." 숫자는 예시입니다.

긴급 페이지의 `architecture.md`에는 페이지의 일(전화 우선), 광고 문안 그대로, 둘째 길(이름·전화·무슨 일의 "카카오로 답 주세요" 또는 채널 버튼), 전화 우선 스택에서 남긴 섹션과 자른 둘(가격은 진행 방식에 접고, FAQ는 네 질문), 마찰(필드 3, 리뷰 플레이스로 나가는 링크 1)이 있습니다.

## 지역이 아닌 대조

"10인 이하 팀 무료" 광고를 돌리는 소프트웨어에는 이 섹션이 필요 없습니다. 전화 막대도, 상권도, 견적 방문도 없습니다. 그 페이지는 본 스킬의 콜드 또는 따뜻한 목록 스택을 따르고, 약속 일치는 그대로입니다. 히어로에 "10인 이하 팀 무료"가 같은 말로 있습니다. 예시 제품은 북산일정(다지점 일정 소프트웨어)입니다.
