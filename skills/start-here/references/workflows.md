# 더 있는 작업 흐름

사용자가 이 사슬 중 하나를 청하거나, SKILL.md의 표가 요청을 안 덮을 때 읽습니다. SKILL.md와 같은 규칙. 3단계 이상은 계획을 먼저, 서로 안 의존하면 병렬, 시간은 벽시계입니다.

### 레터를 시작
```
/newsletter (형식과 첫 호)
→ (parallel: /lead-magnet 받는 이유 + /email-sequences 환영)
→ /content-atomizer 출시 알림
```
약 25분에서 35분. 한국에서 환영의 기본 경로는 이메일보다 카카오 채널, 알림톡, 친구톡, 문자가 앞입니다. 광고성이면 시작에 (광고), 보내는 이, 수신거부. 야간 21시에서 08시는 별도 동의. 자동 발송은 하지 않습니다.

### AI에 인용되기 ("챗지피티나 AI 답변에 있나?")
```
/ai-search (모델 점유 감사)
→ /seo-content 새로고침 (감사가 표시한 페이지를 고침)
→ 인용 모니터 루틴 (automations/)
```
감사와 첫 수정은 약 20분에서 30분. 인용 집합은 달마다 바뀌므로 모니터는 반복이 설계입니다. 한국 표면은 네이버 Cue:, 네이버 AI 브리핑, ChatGPT, Perplexity, Google AI Overview입니다. 영어 웹의 인용 비율은 네이버로 옮기지 않습니다. 인용되는 한국어 출처는 공식 사이트, 블로그, 카페, 지식iN, 뉴스, 유튜브입니다.

### 월간 리뷰 ("어떻게 되어 가나")
```
/performance-review (실제 숫자) → 보내진 수정
```
리뷰가 learnings.md에 사전 믿음을 쓰고, 이미 스킬에 매핑된 행동 3개에서 5개를 돌려줍니다. 약 15분에서 25분, 그다음 수정. 광고를 하는 지역 사업은 분기에 한 번, 또는 예산을 크게 바꾼 뒤에 /ads-incrementality-check를 더합니다. 숫자는 가져온 것만. 없으면 추정이라고 말하고 `~`를 붙입니다.

### 프로그래매틱 SEO ("X마다 페이지")
```
/keyword-research (패턴과 수식어 집합을 검증) → /programmatic-seo
```
패턴을 검증하는 것은 200페이지를 만들기 전의 싼 보험입니다. 약 30분에서 45분. 동마다 페이지를 원하는 지역 사업은 /local-seo-plan 다음 /service-area-pages로 갑니다. 동은 데이터 열이 아니라 실제 지역 증거가 필요합니다. 키워드의 무료 경로는 네이버 자동완성, 연관검색어, 데이터랩, 검색광고 키워드도구입니다.

### 지역 출시 (새 장소나 새 서비스)
```
/google-business-profile (플레이스와 첫 달 소식)
→ (parallel: 새 동이나 서비스의 /service-area-pages + /reviews 부탁 설정)
→ /paid-ads (작게, 넓은 캠페인 하나). 전화가 안 세면 먼저 집계
```
약 45분에서 60분. `/google-business-profile`의 일은 네이버 스마트플레이스입니다. 카카오맵은 다음. 구글 비즈니스 프로필은 구글 검색이나 외국인 손님이 필요할 때만. 광고는 파워링크, 플레이스 광고, 브랜드검색이 먼저이고, 메타, 계정이 있으면 구글입니다. 가짜 리뷰와 별점 조작은 하지 않습니다.

### 대행사 온보딩 (계약한 고객사)
```
new client <url> (./brands/<slug>/에 가벼운 읽기)
→ 가벼운 보고의 첫 행동
→ 유지가 전략을 덮으면 "깊게"
```
약 3분, 그다음 첫 수정. 연락은 상호와 이름으로, 밤에는 하지 않고, 긴 영어식 콜드메일 대신 짧은 정중한 제안, 고칠 문제 하나, 성과 약속 없음. 영업 목록의 무료 경로는 네이버 검색, 플레이스, 지도를 손으로 확인하는 것입니다.
