# 결정 예시 (예시 업체)

`/local-seo-plan` 7단계 전에 읽어요. 한빛설비(대구, 설비)는 예시 업체예요. 아래 숫자는 모두 예시이고, 추론의 모양을 보여 주기 위한 것이에요. 실제 자료가 아니에요.

## 여섯 가지 결과, 각각이 맞을 때

**1. 새 서비스 페이지.** 지역 상업 수요가 있고, 그 일을 반복해서 하고, 결제 건이 여러 개에 확인된 결과가 하나 이상이며, 페이지에 증거·범위·제외를 실을 수 있어요. 부모 페이지부터 만들어요. "보일러 수리·교체". 종류나 브랜드 페이지를 먼저 만들지 않아요.

**2. 기존 페이지 개선.** URL과 수요는 있는데 페이지가 얇거나 의도 둘을 섞어요. 한 페이지가 "배관 청소"와 "하수관 교체"를 같이 노리는 경우. 능력은 있지만 새 URL을 나눌 정도는 아니에요.

**3. 기존 페이지의 단락.** 수요와 증거가 작은 하위 서비스. 부모 페이지의 소제목과 단락. 나중에 자기 페이지를 벌 수 있는지도 알려 줘요.

**4. 현장 이야기.** 증거가 유난히 강한 출장 하나. 설비, 문제, 동, 결과가 다 있고, 가능하면 리뷰와 가린 사진. 예시 하나라고 솔직해요. 모든 브랜드, 모든 동을 한다고 읽히면 안 돼요.

**5. 글.** 증상과 방법 수요("보일러 탕탕 소리", "보일러 아래가 새는 이유"). 진단 설명을 안전하게 할 수 있을 때. 전문 서비스 페이지가 없어도 돼요.

**6. 보류.** 그 일을 안 함. 면허, 보험, 안전, 폐기가 안 풀림. 검색 의도가 다른 업종. 기존 페이지의 얇은 변종 하나 더. 자료 없음은 이 목록에 없어요. 가는 동은 발행 기준 뒤의 페이지 목록으로 가요. 보류는 이유와 무엇을 채우면 열리는지 한 줄이에요.

## 작업 예시

**결정 기록.** 스킬 1단계에 적은 것과 같아요.

**능력 장부 (일부).** 숫자는 예시예요.

| 서비스 | 12개월 결제 (합친 뒤) | 지역 | 증거 등급 | 사진 | 한계 | 확인 |
|---|---|---|---|---|---|---|
| 보일러 수리·교체 | 약 40 | 수성구, 중구, 동구, 달서구 | 3 (리뷰가 말함) | 있음 | 가스는 자격 있는 기사 | 사장님, 날짜 |
| 순간 온수기 설치 | 약 6 | 수성구, 중구 | 2 (메모만) | 가린 사진 2 | 브랜드 둘만 | 사장님, 날짜 |
| 누수 탐지·수리 | 약 12 | 수성구, 달서구 | 3 | 있음 | 배관 교체만, 굴착 없음 | 사장님, 날짜 |
| 가스 배관 신규 | 약 2 | 수성구 | 1 (결제만) | 없음 | 면허 확인 전 | 아직 |
| 하수관 교체 | 0 | | | | 외주 | 아니오 |

**시장 지도 (일부).** 칸: 수요 / 그 지역 중심 "근처" 플레이스 / "서비스 지역" 웹 검색 / 우리 페이지 / 지역 증거. 예시예요.

| | 수성구 | 중구 | 경산시 |
|---|---|---|---|
| 보일러 | 있음 / 상위 3 밖 / 홈이 9위 / 전용 페이지 없음 / 출장 많음 | 있음 / 3위 / 상위 20 밖 / 없음 / 8건, 리뷰 2건이 중구 | 있음 / 상위 20 밖 (핀이 멈) / 상위 20 밖 / 없음 / 1건 |
| 누수 | 있음 / 2위 / 5위 / 얇은 페이지 / 출장과 리뷰 | 바닥 구간 / 미확인 / 상위 20 밖 / 없음 / 3건 | 보고할 추정치 없음 / 미확인 / 미확인 / 없음 / 0 |
| 가스 배관 | 있음 / 미확인 / 대리점과 전문 업체 / 없음 / 결제 2건 | | |

**결정.**

1. **보일러, 수성구. 새 부모 서비스 페이지.** 수요, 증거 3등급, 홈이 그 검색어를 9위로 엉성하게 맡고 있음. 페이지가 생기면 홈은 그 정확한 검색어를 멈추지 않으면 둘이 싸워요.
2. **보일러, 중구. 지역 페이지.** 플레이스 3위, 웹은 없고, 출장 8건과 중구를 말하는 리뷰 둘. `/service-area-pages`가 중구에서만 참인 말을 쓸 수 있어요.
3. **누수, 수성구. 기존 페이지 개선.** 얇은 페이지로 5위. 일의 내용, 리뷰, 굴착 없음, 사진을 넣어요.
4. **누수, 중구. 단락.** 바닥 구간, 3건. 누수 페이지 안의 중구 문장과 서비스 지역 페이지의 한 줄. 건수나 노출이 늘면 다시 봐요.
5. **순간 온수기. 보일러 페이지의 단락과 현장 이야기 하나.** 6건, 2등급은 하위 페이지 막대(결과 3, 사진, 다른 검색 의도)에 못 미쳐요. 기록이 가장 좋은 설치가 현장 이야기가 돼요.
6. **경산시. 10주의 지역 페이지, 발행 기준 뒤.** 차는 가지만 1건, 핀이 멀고, 경산을 말하는 리뷰가 없어요. 10주에 기준을 못 채우면 서비스 지역 페이지의 한 줄로 남고 자리는 다음 동으로 가요.
7. **가스 배관 신규. 보류.** 결제는 있으나 면허 확인 전, 사진 없음. 열림: 면허를 글로 확인, 기록된 3건, 사장님 확인.
8. **하수관 교체. 보류.** 외주. 페이지가 기사가 안 하는 일을 주장하게 돼요. 열림: 직접 하게 될 때.
9. **브랜드 페이지. 보류.** 브랜드 결과는 제조사와 대리점이 차지하고, 장부에 브랜드별 결과가 없어요. 브랜드를 언급한 현장 이야기가 얇은 브랜드 페이지보다 나아요.

## 이 예시가 피하는 실수

- 틀이 쉽다고 서비스 × 동 칸마다 페이지를 만듦.
- 인구가 크다고 경산 페이지를 일찍 발행함. 기준이 나갈 날을 정함.
- 대구광역시, 수성구, "대구 보일러"의 전국 검색량을 더해 페이지를 정당화함.
- "가스 배관" 클릭 비용이 높다고 페이지를 만듦.
- 홈이 서비스 검색 9위인 것을 "이미 있음"으로 봄.
- 장부가 올 때까지 모든 동 페이지를 보류함. 발행 기준이 이미 어느 것이 나갈지 정함.
