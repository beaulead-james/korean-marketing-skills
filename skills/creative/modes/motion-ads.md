# 모션 광고 모드

실제 촬영이나 생성 영상을 코드로 잘라 MP4로 렌더합니다. 자막, 후기 카드, 제안, 끝 카드, 후크 변형. 모델 키도 렌더당 요금도 없습니다. HyperFrames가 기본입니다. 글자만 움직이는 모션은 SaaS 화면 녹화나 제안 범퍼에만 씁니다. 실물 제품이나 현장 일의 본 광고에는 영상이 있어야 합니다.

바닥입니다. 더 나은 컷이 있으면 그 길을 가고 이유를 한 줄로 말합니다. 셀 ID 이름은 유연하지 않다.

## 우리가 쓰는 것

- **HyperFrames** (HeyGen, Apache-2.0). HTML과 GSAP. CLI가 이 기계에서 MP4. Node 22+, FFmpeg. 시작 파일은 `references/motion-ads-starter.html`.
- **Remotion**은 대안입니다. 회사 규모에 맞는 라이선스를 확인한 뒤에만.
- 음성 타이밍. `hyperframes transcribe`. 로컬 음성 모델. 처음 쓸 때 설치됩니다.
- 생성 영상이 필요하면 역할은 `video-ugc` 또는 `video-draft`. 페이로드는 `references/MODEL_REGISTRY.md`. 자른 뒤에는 다시 이 모드.

## 먼저 모을 것

- 클립. 가능하면 실제. 9:16에 가깝게. 사장님, 손, 현장, 제품.
- 끝 카드용 실제 사진. 사용 중인 9:16. 단색 위 팩샷이 아닙니다.
- 후기 원문, 이름(성만 이니셜로 줄일 수 있음), 출처(네이버 영수증 리뷰, 방문 인증). 별점은 그 후기에 있었을 때만. 없는 후기를 짓지 않습니다.
- 제안 문장. 6단어 안. 가격은 원. 조건은 평문으로.
- 브랜드 키트의 색과 폰트 파일. `assets/fonts/`에 자가 호스트. CDN 폰트에 렌더를 의존하지 않습니다.

의료·대부·금융·건강기능식품 문안은 화면에 올리기 전에 업종 심의 경고를 붙입니다. 표시광고법. 거짓·과장, 기만, 부당 비교 금지.

## 작업 흐름

```
# 1. 모든 클립을 프레임에 먼저 맞춘다 (폰은 크기와 프레임레이트가 제각각이다):
ffmpeg -i in.mp4 -vf scale=1080:1920:force_original_aspect_ratio=increase,crop=1080:1920 -r 30 -c:v libx264 -pix_fmt yuv420p -c:a aac assets/clips/body.mp4

# 2. 자막용 단어 타이밍 (로컬 음성 모델, 처음 사용 때 설치):
npx hyperframes transcribe assets/clips/body.mp4

# 3. references/motion-ads-starter.html 로 index.html 을 쓴다. 폰트는 assets/fonts/ 에 자가 호스트.
# 4. 같은 프로젝트에서 후크 변형:
npx hyperframes render --variables '{"hookClip":"assets/clips/hook-b.mp4","hookText":"두 번째 오프닝"}' \
  --output out/hook-b.mp4
```

플래그는 그대로 둡니다. 출력 경로는 캠페인 트리에 맞춥니다. 2026-11-16에 끝까지 시험한 버전은 0.9.8입니다. 같은 버전으로 검사하고 렌더합니다.

```bash
npx hyperframes@0.9.8 check --json 2>/dev/null
npx hyperframes@0.9.8 snapshot --at 0,1,3.5,5,8,11,14.5 --no-end --json
npx hyperframes@0.9.8 render --quality delivery --fps 30 --output renders/MA-H2-B-9x16-v1.mp4
npx hyperframes@0.9.8 render --quality delivery --fps 30 \
  --variables '{"hookClip":"assets/clips/hook-b.mp4","hookText":"두 번째 오프닝"}' \
  --output renders/MA-H2-B-9x16-var-hook-2-v1.mp4
```

렌더 전에 스냅샷 연락 시트를 읽고, 렌더 뒤에 MP4에서 프레임을 읽습니다.

## 렌더를 깨끗하게 하는 작성 규칙

- 시간을 가진 요소는 모두 최상위 `.clip`이고 `data-start`, `data-duration`이 절대 초다.
- 시작 시 숨김은 타임라인 밖의 `gsap.set`입니다.
- 요소당 트윈 하나.
- 말이 있는 `<video>`만 소리를 둡니다. 비롤은 `muted`.
- 자막은 2~4단어. 그 단어들이 말하는 동안 유지. 최소 약 1.1초. 단어는 자기 시작 시각에 켜진다.
- 글은 x 120~888, y 288~1248. y 840 아래에서는 x 780의 왼쪽. 릴스·틱톡·쇼츠 UI가 먹는 자리다.
- 0프레임에 후크 글 상자가 이미 있습니다. 페이드인으로 첫 프레임을 비우지 않습니다.
- 글은 민 그라데이션 위에 두지 않습니다. 영상이나 실제 사진 위다.
- 후크 변형은 클립과 줄만 바꿉니다. 본문 타임라인을 복제해 고치지 않습니다.

## 크기와 안전 영역

마스터는 1080×1920, 9:16. 릴스, 틱톡, 쇼츠가 한 마스터를 공유합니다. 피드 4:5가 필요하면 가운데를 크롭하고 글이 y 420~1500에 있는지 다시 봅니다 (`modes/ad-creative.md`의 메타 크롭). 파워링크에는 이 영상을 넣지 않습니다. 파워링크는 문안입니다.

## 자르는 방식

- **후크 클립.** 얼굴 또는 손과 제품이 첫 프레임부터. 말 유지. 0~약 3초.
- **본문.** 사용. 말 유지. 단어 자막.
- **증거.** 결과의 무음 비롤 위에 실제 후기 카드. 읽을 시간 약 3초.
- **끝 카드.** 실제 사진이 프레임을 채웁니다. 제안, 조건, CTA. 2초 넘게 유지. CTA는 전화, 카카오, 예약 중 하나.
- **댓글 답.** 후크 상자 대신 말풍선. 댓글은 쓰인 그대로. 동의 없으면 이름과 사진을 가립니다.
- **화면 녹화.** SaaS(예시. 북산일정)만 글자 모션을 본편으로 쓸 수 있습니다. 그래도 첫 프레임에 화면이 있어야 합니다. 빈 그라데이션에 키네틱 타이포만 두지 않습니다.

## 생성 영상

촬영이 없으면 `video-ugc`로 비롤을 만들고 이 모드에서 자릅니다. AI 진행자가 고객의 1인칭으로 결과나 고백을 말하지 않게 합니다. 통념, 팁, 질문, POV는 가능합니다. 후기는 실제 문장만 카드에 올립니다. 생성 클립을 고객이 찍은 것처럼 캡션하지 않습니다.

## 짝

- 광고 셀이면 파일 이름은 `MA-H2-B-9x16-v1.mp4`.
- 썸네일이 필요하면 0프레임 또는 끝 카드 직전을 `modes/social-graphics.md`에 넘깁니다.
- 문안이 비면 `/direct-response-copy`가 아니라 이 모드의 한 줄 제안으로 충분할 때 그렇게 적습니다. 긴 판매 문장은 그 스킬로.

## 품질 점검

- 소리 없이 첫 1초에 후크가 읽힙니다.
- 제품이나 현장이 2초 안에 보입니다.
- 자막이 UI에 가리지 않습니다. 안전 영역.
- 후기 카드의 말이 원문과 같습니다. 출처가 있습니다.
- 끝 카드 약속이 랜딩 첫 문장과 같습니다.
- 다른 브랜드 워터마크, 가짜 UI, 지어낸 전화번호가 없습니다.
- 렌더가 1080×1920, 30fps, 소리 있는 클립은 소리가 있고 비롤은 없습니다.

## 모션의 비전 QA

렌더러 스냅샷 연락 시트를 렌더 전에 읽습니다. 렌더 뒤 ffmpeg로 처음, 중간, 끝 프레임을 읽습니다 (`references/api-workflow.md` 2절). 7 미만이면 그 결함만 고칩니다. HTML이나 타이밍. 모델을 다시 돌리기 전에 코드로 고칠 수 있는지 봅니다. 점수는 매니페스트에만.

## 이름과 출력

`creative-output/ad-creative/<campaign>/` 또는 캠페인 트리. 버전을 올립니다. 덮어쓰지 않습니다. `./brand/assets.md`에 한 줄. 채팅에는 경로, 무엇인지, 남은 결함 한 줄, 출처(실제 클립인지 생성인지, 후기 출처).

## 작업 예. 현장 기사 광고 (예시. 한빛설비, 대구)

후크 글. "온수기가 오늘 아침 멈췄습니다". 본문 자막은 기사가 실제로 한 말의 타이밍. 후기 카드. 네이버 영수증 리뷰 원문, 성 이니셜, "네이버 리뷰". 끝 카드. 현장 사진, "당일 출동, 견적 후 시작", "대구 수성·달서", "전화하기". 가격을 넣으면 원이고, 견적에 있는 금액만. 후크 변형은 두 번째 줄만 바꿉니다. "배관 청소제를 넣기 전에". 셀 ID가 있으면 `MA-H2-B-9x16-v1.mp4`.
