# 제품 사진 모드

제품 정지 사진을 만들거나, 사용자가 가진 실제 사진을 고칩니다. 쇼핑몰, 상세 페이지, 광고의 소스 프레임. 역할로 라우팅합니다. 모델 ID는 `references/MODEL_REGISTRY.md`. 호출은 `references/api-workflow.md`. QA는 SKILL.md의 비전 루프에 이 파일의 추가 항목을 더합니다.

예시 업체. 실물은 한빛설비의 부품이 아니라, 제품이 있는 경우의 촬영 어휘입니다. 소프트웨어 화면은 북산일정(다지점 일정). 없는 제품을 있는 것처럼 찍지 않습니다.

## 먼저. 편집이냐 생성이냐

- **편집.** 실제 사진이 있습니다. 제품의 형태, 색, 라벨이 살아야 합니다. `image-instruct-edit` (GPT Image 2.6 Sunburst, 초안은 Flare). 이전 출력을 다시 넣고 한 번에 하나만 바꿉니다. 구글 계열 편집은 `image-default`의 `image_input`.
- **생성.** 사진이 없고 방향을 탐색합니다. `image-default`. 정확한 구도나 장면 안 글자는 `image-complex-prompt`. 출고할 4K만 `image-premium-4k`.
- 광고에 올릴 문자는 이미지 안에 굽지 않습니다. HTML로 얹습니다. 라벨처럼 제품에 속한 글만 모델에 맡깁니다.

키가 없으면 프롬프트 전용. 같은 판단, 파일 대신 프롬프트.

## 편집. 사용자의 실제 사진

1. 원본을 참조로 넣습니다. 프롬프트는 바꿀 것만 말합니다. "배경을 흰 심리스로, 제품은 그대로."
2. 한 라운드에 변수 하나. 배경, 또는 조명, 또는 크롭. 셋을 같이 바꾸면 무엇이 망가졌는지 모릅니다.
3. 라벨 글자, 비율, 색이 원본과 같은지 눈으로 봅니다. 다르면 그 축만 다시.
4. 시드를 지원하는 모델은 시드를 고정합니다. 나노바나나 계열은 시드가 없으면 이긴 출력을 `image_input`으로 되돌립니다.

## 샷 어휘

| 샷 | 쓰는 때 | 비율 |
|---|---|---|
| 히어로 | 첫 화면, 광고 소스 프레임 | 16:9 또는 4:5 |
| 디테일 | 재질, 이음, 라벨 | 1:1 또는 4:5 |
| 라이프스타일 | 쓰이는 장소 | 4:5 |
| 플랫레이 | 구성품이 한눈에 | 1:1 |
| 스케일 | 크기 비교 | 1:1 |
| 커머스 메인 | 마켓 대표 이미지 | 채널 규칙 |

## 업종 판단

- **현장 서비스(한빛설비 예시).** 제품 팩샷보다 현장 사진이 신뢰를 만듭니다. 생성 현장을 실제 시공처럼 캡션하지 않습니다. "예시 장면"이라고 파일 노트에 적습니다.
- **소비재.** 사용 장면이 흰 배경보다 스크롤을 멈춥니다. 마켓 대표 이미지는 채널 규칙을 먼저.
- **소프트웨어(북산일정 예시).** UI는 실제 화면 캡처를 편집합니다. 없는 버튼을 그리지 않습니다.
- **음식.** 김이 나 식욕이 나는 빛. 플라스틱 광택이 나면 다시.
- **주얼리·스킨케어.** 극접사와 통제된 반사. "럭셔리"만 붙이지 말고 조명 방향을 말합니다.

## 조명

아마추어와 프로의 선은 조명 방향입니다. 광원 하나, 어디서 오는지, 림이 있는지. "스튜디오 조명"만 쓰면 평평해집니다. 창가 아침, 왼쪽 위 스포트, 약한 림. 하나 고르고 세트 안에서 유지합니다.

## 배경, 스테이징, 구도

배경은 포지션을 돕습니다. 프리미엄은 어둡고 단순. 친근은 실제 방의 약간의 어지러움. 제품이 프레임의 주인입니다. 소품은 이야기를 하나만 합니다. 여백은 나중에 얹을 한 줄 글을 위해 남깁니다. 3분할은 초점을 교차점에 둘 때 씁니다. 가운데도 정당한 상업 샷입니다. 이유를 한 줄.

## 여러 샷의 일관성 잠금

다섯 장을 한 세트로 낼 때, 프롬프트의 첫 절만 샷이 다르고 쉼표 뒤는 잠금 문구를 그대로 둡니다.

```
히어로 (16:9). 드립퍼가 떠 있음, [잠금]
디테일 (1:1). 드리퍼 주둥이 접사, [잠금]
라이프스타일 (4:5). 부엌 카운터, 아침, 김, [잠금]
플랫레이 (1:1). 필터, 원두, 스쿱, 머그, 위에서, [잠금]
스케일 (1:1). 표준 머그 옆, 비율이 보이게, [잠금]
```

`[잠금]`은 팔레트, 조명 문구, 렌즈, 피할 것을 한 덩어리로. 샷마다 다시 쓰지 않습니다.

## 채널 규칙

전달 전에 마켓 작업은 채널 규칙을 적용하고, 실패하면 고쳐서 다시 만듭니다.

**쿠팡·스마트스토어 대표 이미지.** 판매자 센터의 현재 규칙을 따릅니다. 여기 픽셀을 단정하지 않습니다. 흔히 요구되는 방향은 흰 배경, 제품만, 글·로고·워터마크 없음입니다. 화면이 다르면 화면이 이깁니다.

**아마존 미국 메인.** 순백 RGB 255,255,255, 제품이 프레임의 85% 이상, 글·로고·워터마크·테두리 없음, 제품 하나, 소품 없음, 선명, 실제 색, 1500×1500 목표. 보조 이미지는 라이프스타일·인포그래픽·스케일이 가능합니다. 한국 마켓의 규칙으로 옮기지 않습니다. 미국 채널을 할 때만.

**자사몰.** 1:1, 한 변 약 2048px, 카탈로그 배경 일치, 제품당 각도 3~5. 히어로와 라이프스타일은 자유.

**자동 수정.** 배경이 하얗지 않으면 "순백 심리스 배경, RGB 255 255 255"를 붙입니다. 제품이 작으면 "프레임의 85퍼센트를 제품이 채움". 소품이 있으면 맥락 절을 빼고 "제품만, 소품 없음". 색이 틀리면 "정확한 색, 중립 화이트밸런스".

**인스타.** 피드는 1:1보다 4:5가 화면을 더 차지합니다. 대비. 라이프스타일이 스튜디오보다 스크롤을 멈추는 경우가 많습니다. **히어로 배너.** 16:9 또는 21:9, 제목 공간을 명시. **핀터레스트.** 2:3 세로, 위쪽에 글 공간. 한국 기본 소셜은 인스타, 스레드, 네이버 블로그 썸네일, 쇼츠 썸네일입니다.

## 프롬프트 예 (완전)

모델에 넣는 문장입니다. 광고 문안은 여기 넣지 않습니다.

```
기술 히어로     프리미엄 무선 오버이어 헤드폰, 실버와 블랙, 어두운 차콜 그라데이션 위에 떠 있음,
                왼쪽 위 스포트 하나, 가장자리 약한 림, 통제된 금속 반사, 오른쪽에 제목 여백,
                상업 기술 광고 사진, 선명, 16:9

스킨케어 플랫   유리 드로퍼 세럼, 황금색 내용물이 보임, 순백 배경, 부드러운 확산 스튜디오 빛,
                프레임의 85퍼센트, 정확한 색, 상업 뷰티 사진, 1:1

음식 라이프     크라프트 원두 봉투, 원두가 보이는 창, 나무 부엌 카운터, 아침 창가 빛,
                흩어진 원두, 근처 도자기 머그, 따뜻한 톤, 편집 음식 사진, 4:5

주얼리 접사     다이아몬드 링, 플래티넘 밴드, 브릴리언트 센터, 극접사, 컷면의 반짝임,
                검은 그라데이션, 통제된 반사, 금속 가장자리 림, 하이엔드 상업 사진, 1:1
```

## 80/20

결과의 80%. (1) 구체적인 제품 묘사, (2) 방향이 있는 조명, (3) 포지션을 돕는 배경, (4) 채널에 맞는 구도. 좋은 것과 훌륭한 것을 가르는 20%. 여러 샷의 일관성, 참조 이미지(편집), 리스팅이 튕기지 않는 규칙 준수, 한 장짜리가 아닌 세트.

## 이 모드의 QA 추가

표준 루브릭 위에. 제품 정확(보이는 특징, 색, 편집 모드에서 원본 대비 비율), 상업적으로 읽히는가(유료 촬영으로 통과할 것인가), 채널 규칙, 피할 목록. 흔한 고침. AI처럼 보이면 카메라·필름 참조를 구체적으로. 반사가 틀리면 "통제된 반사". 평평하면 빛 방향. 산만하면 소품을 뺀다. 프리미엄이 아니면 스테이징을 늦추고 배경을 어둡게 합니다. "럭셔리"만 붙이지 않습니다.

## 출력

api-workflow.md. `creative-output/product-photos/<product>/<shot-type>/` (편집은 `edits/`). 이름 `[shot]-[descriptor]-[ratio]-v[N].png`. 매니페스트 갱신. `./brand/assets.md`에 한 줄. 전달은 샷과, 어디에 맞는지 한 줄. QA 점수는 매니페스트. 한 장이 잘 나오면 일관성 잠금과 세트 확장을 제안합니다. 승인된 히어로는 product-video의 I2V 소스 프레임. 승인된 세트는 ad-creative의 재료.
