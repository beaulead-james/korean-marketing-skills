# 소셜 그래픽 모드

게시, 썸네일, 인용 카드, 콘텐츠 달력의 정지 그래픽. 역할은 `image-default`. 글자가 6단어를 넘거나 글자마다 맞아야 하면 `image-text-render` 또는 `image-complex-prompt`로 장면을 만들고, 문장은 HTML로 얹는 쪽을 기본으로 합니다. 모델이 긴 한글을 틀리게 굽는 일이 많습니다.

한국에서 발견되는 면. 네이버 블로그 썸네일, 인스타그램 피드·릴스 커버, 스레드, 유튜브 쇼츠·영상 썸네일. 링크드인·핀터레스트·X는 그 계정이 있을 때. 블로그 체험단·협찬은 대가성 표시.

## 매체 스펙과 시각 언어

| 면 | 비율 | 글 |
|---|---|---|
| 인스타 피드 | 4:5 우선, 1:1 가능 | 한 줄. 나머지는 캡션 |
| 메타 피드 광고 | 1:1, 4:5, 9:16 | 글자는 HTML. 아래 CTA 영역을 비움 |
| 릴스·쇼츠 커버 | 9:16 | 위 14%, 아래 35%를 비움 |
| 플레이스 소식 이미지 | 정사각으로 시작 | 매장·작업. 슬로건은 소식 본문 |
| 카카오 | 가이드의 정사각·세로 | 혜택 한 줄. 픽셀은 가이드 확인 |
| 블로그 썸네일 | 채널이 자르는 비율을 먼저 봅니다. 보통 가로 | 제목이 잘려도 주제가 보이게 |
| 유튜브 썸네일 | 1280x720 | 얼굴 또는 제품, 단어 셋 안 |
| 스레드·X | 1:1 또는 16:9 | 타임라인에서 읽히게 대비 |
| 링크드인 | 1.91:1 또는 1:1 또는 4:5 | 계정이 있을 때. 과장 문구 없음 |
| 핀터레스트 | 2:3 | 계정이 있을 때. 위쪽 글 공간 |

정확한 픽셀은 각 매체가 바꾸므로, 업로드 화면이 다르면 화면이 이깁니다. 2026-09-02에 본 영어권 참여율 순위는 `references/VISUAL_INTELLIGENCE.md`에 있고 한국 도달률이 아닙니다.

## 프롬프트 템플릿

글은 이미지 밖에 둡니다. 프롬프트는 장면만.

```
블로그 썸네일   대구 주택 보일러 옆의 손, 창가 빛, 가로 구도, 왼쪽 여백, 글자 없음
쇼츠 커버       같은 장면의 세로, 얼굴 또는 손이 가운데 밴드, 위아래 여백, 글자 없음
인용 카드 배경  종이 질감, 브랜드 색 하나만, 가운데 비움, 글자 없음, 1:1
썸네일          놀라지 않은 실제 표정에 가까운 얼굴 또는 제품, 고대비, 오른쪽 여백, 16:9
```

## 그래픽 안의 글. 렌더냐 합성냐

- **합성 (기본).** HTML/CSS로 브랜드 폰트를 얹고 PNG. 철자, 조사, 줄바꿈을 통제합니다. 광고 문안, 가격, 상호는 이쪽.
- **모델 렌더.** 장면에 속한 간판, 포장 라벨, 손글씨 한 단어. `image-text-render` 또는 GPT Image 2.6. 따옴표 안에 정확한 글자. 한글 문장 전체를 맡기지 않습니다. 내보낸 뒤 글자를 읽습니다. 한 글자라도 틀리면 합성으로 바꿉니다.

가격은 원. "최고", "1위"는 근거가 있을 때만. 표시광고법.

## 유튜브 썸네일

가장 비싸게 실패하는 그래픽입니다. 1280x720에서 휴대폰으로도 주제가 보여야 합니다. 얼굴 또는 제품, 대비, 단어 셋 안. 가짜 화살표와 가짜 재생 버튼은 쓰지 않습니다. 영어권 연구의 "얼굴이 있는 썸네일이 더 낫다"는 그 연구의 결론이지 한국 쇼츠 법칙으로 단정하지 않습니다. 얼굴이 브랜드에 맞으면 쓰고, 아니면 제품을 씁니다.

## 콘텐츠 뼈대

- **인용.** 고객 원문. 길면 줄이고 생략을 표시. 출처.
- **전후.** 같은 각도. 몸·소득은 제외. 현장은 실제 사진만.
- **체크리스트.** 3~5항목. 글은 HTML.
- **숫자.** 출처가 있는 것만. 예시는 예시.
- **사람.** 실제 직원이나 승인된 진행자. 모르는 얼굴을 직원처럼 캡션하지 않습니다.

## 템플릿. 규모에서의 일관성

캠페인에 템플릿을 하나 적고 재사용합니다.

### 템플릿. <이름>

- 비율, 여백, 글 위치, 브랜드 색 hex, 폰트
- 바뀌는 것. 사진과 한 줄
- 안 바뀌는 것. 잠금 문구
- 저장. `./brand/creative-kit.md` 또는 캠페인 `style-lock.md`

## 여러 매체 적응

한 장면을 늘려 맞추지 않습니다. 4:5를 먼저 구도를 잡고, 9:16은 위아래를 다시 찍거나 다시 생성합니다. 16:9 썸네일은 얼굴을 안전하게 다시 배치합니다. 블로그 가로는 왼쪽 여백을 따로 둡니다.

## 콘텐츠 달력 모드

한 주 이상이면 생성 전에 표를 씁니다. 날짜, 면, 한 줄, 비율, 파일 이름, 상태. 3개 이상이면 매니페스트(api-workflow.md 4절). 한 번에 5~8장. 게시하지 않습니다. 파일까지입니다. 자동 게시 금지.

## QA 추가

표준 위에. 휴대폰에서 한 줄이 읽히는가. 한글이 깨졌는가. 안전 영역에 글이 있는가. 대가성 표시가 필요한 게시인가. 피할 목록. 다른 브랜드 로고.

## 출력

`creative-output/social-graphics/<campaign>/<platform>/`. 이름 `[type]-[descriptor]-[ratio]-v[N].png`. `./brand/assets.md` 한 줄. 승인된 세트는 `/content-atomizer` 또는 `/social-content`로. 광고면 셀 ID로 ad-creative에 합류.
