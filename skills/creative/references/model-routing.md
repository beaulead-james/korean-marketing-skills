# 모델 라우팅. 작업에서 모델로

```
last-verified: 2026-11-18
ttl-days: 90
refresh: scripts/verify_models.sh로 모델이 살아 있는지 다시 확인하고, 종료가 가까운 것은 공개 모델 페이지를 봅니다. 최근 생성과 운영 선행이 어긋나면 이 파일의 기본값을 고칩니다.
changes: 2026-11-18 본문을 한국어로 옮겼습니다. 가용성, 스키마, 가격의 검증일은 2026-11-13입니다(25/25 통과). 그 날짜의 모델 사실을 바꾸지 않았습니다. 2026-11-16에 image-complex-prompt와 image-instruct-edit가 GPT Image 2.6으로 연결됩니다. Flare는 초안, Sunburst는 최종과 일관된 수정. 스키마와 가격은 2026-11-16에 읽었습니다. Sora 2와 Sora 2 Pro는 사라졌습니다(API 2026-09-24 종료, 페이지 404). video-ugc는 Seedance 2.0, 대안은 Veo 3.1, Seedance 2.0은 히어로 트리오에 있습니다. 비디오 입력이 없으면 Seedance 2.0이 더 쌉니다. 6절은 가용성만 다시 봤습니다. ElevenLabs와 HeyGen ID 여덟 개가 Replicate에 살아 있었습니다. 운영 선행의 마지막 재시험은 2026년 6월입니다. 선행이지 측정이 아닙니다.
```

스타일 락, 승인된 진행자 팩, 사용자가 지명한 모델로 이미 고정되지 않았을 때, 모델을 고르기 전에 이 파일을 읽습니다. 판단 층이 여기 있습니다. 어느 작업에 어느 모델인지, 텍스트인지 이미지인지 참조인지, 브랜드 룩이 세션과 모델을 넘어 어떻게 사는지.

여기의 모든 것은 이유가 있는 **기본**입니다. 상황이 다르면 자유롭게 벗어나고, 이유를 한 줄로 말합니다. 기본은 **2026년 6월에 현장에서 시험한 운영 선행**입니다. 가용성, 스키마, 가격은 2026-11-13에 다시 확인했고, 선행 자체는 6월 이후 재시험하지 않았습니다. 번 의견이지 법이 아닙니다. 썩습니다. 최근 생성이 선행과 어긋나면 조용히 우회하지 말고 이 파일을 고칩니다.

모델 이름을 라우팅 표에 적는 파일은 여기와 MODEL_REGISTRY.md뿐입니다. 역할과 이름, 판단을 위해. 페이로드, 파라미터, 가격은 `references/MODEL_REGISTRY.md`에만 있습니다. 호출 전에 거기서 역할을 풉니다.

## 2. 입력. t2v, i2v, i2i, 참조

질문은 "어느 모드가 최고인가"가 아닙니다. **무엇을 지키는가**입니다.

```
아직 지킬 것이 없습니다 (방향 탐색)   → t2i / t2v
실제인 것이 실제로 남아야 합니다     → i2i / 수정
승인된 룩에 움직임이 필요하다         → 승인 스틸에서 i2v
세트 전체의 일관성                    → 참조
움직임에 도착점이 있습니다           → 시작 프레임과 끝 프레임
```

- **t2i / t2v. 탐색.** 지킬 것이 없으니 모델이 상상하게 둡니다. 방향을 찾는 가장 싼 방법입니다. 무언가가 승인되는 순간 텍스트에서 다시 굴리지 않습니다. 정확히 돌아오지 않습니다.
- **i2i / 수정. 충실도가 상상보다 낫습니다.** 실제로 남아야 하는 것, 당신의 제품, 당신의 얼굴, 당신의 패키지와 라벨은 이미지로 넣고 그 주위를 고칩니다. 비슷하게 만든 병은 다른 병입니다. 손님이 압니다. 실제 사진은 `image_input`(NB2 합성) 또는 수정 경로(GPT Image 2.6 Sunburst)로 넘기고, 프롬프트가 말한 것만 바꿉니다. 실제 사람이나 제품을 장르 룩으로 다시 꾸밀 때 참조만으로는 부족합니다. 바뀌면 안 되는 것을 이름 붙입니다. "warm olive skin, NOT dark brown". "matte label, NOT glossy". 명시적으로 부정하지 않으면 모델은 장르 고정관념으로 흐릅니다.
- **i2v. 룩을 다시 굴리지 않는 움직임.** 구도를 스틸로 먼저 잠급니다. 싸고, 몇 초면 반복됩니다. 승인된 뒤 승자를 움직입니다. 첫 프레임이 승인 이미지이고, 프롬프트는 움직임만 말합니다. 단계 파이프라인이 소스 프레임으로 시작하는 이유입니다. t2v는 룩과 움직임을 한 번에 다시 굴립니다. 추첨이 두 개입니다.
- **참조. 세트 일관성.** 캠페인 가족, 반복 인물, 여러 장면에 적용하는 브랜드 스타일. 프롬프트 문장이 같은 룩을 다시 소환하길 바라지 말고 참조를 넘깁니다. Seedance 2.0 참조 배열, Kling Omni `reference_images`, 스틸은 NB2 합성. 승인된 자산 하나가 모든 형제의 닻이 됩니다.
- **시작과 끝 프레임. 움직임에 도착점이 있습니다.** 클립이 어딘가에 닿아야 하면(시퀀스의 컷 포인트, 글자 여백을 잡는 끝 프레임) 끝 프레임을 설정합니다. `end_image`, `last_frame`, `last_frame_image`. 어느 계열인지는 레지스트리 표. 프롬프트로 기도하지 않습니다.
- **이은 시퀀스. 스타일 스틸, i2v, 프레임 잇기.** 5~15초 모델로 15초를 넘기고 장면이 이어지게 하는, 현장에서 시험한 경로. (1) 룩을 그 일에 가장 강한 이미지 모델의 스틸로 정의합니다. 실제 피사체가 있으면 i2i. 승인받습니다. (2) 승인 스틸을 i2v로 움직입니다. 첫 프레임이 스타일 락입니다. (3) 프레임으로 클립을 잇습니다. 클립 N의 마지막 프레임(지원되면 `end_image`, 아니면 ffmpeg로 추출)이 클립 N+1의 시작입니다. wan-2.7-i2v는 이전 클립 자체를 `first_clip`으로 받으므로 컷 사이에서 룩이 다시 굴러가지 않습니다. (4) 크기와 fps를 맞추고 ffmpeg concat. (5) 그림 컷을 먼저 잠그고, 오디오(내레이션, 음악, 효과음)는 후반 한 번에. 시퀀스에 클립마다 오디오를 구워 넣지 않습니다. 양식화된 일러스트 인물은 첫 프레임 i2v와 후반 내레이션이 립싱크보다 낫습니다. 일부 참조 파이프라인은 첫 프레임과 참조 오디오가 양립하지 않고, 양식화 인물은 립싱크 없이도 읽힙니다.

**비용을 지배하는 논리.** 이미지는 몇 센트와 약 30초입니다. 영상은 몇 십 센트에서 몇 달러, 그리고 몇 분입니다. 룩은 이미지 공간에서 정하고, 영상 지출은 승인된 룩에만 합니다. 영상 모델 안에서 룩을 반복하는 것이 가장 비싼 연출입니다. 금액은 레지스트리의 달러입니다.

## 3. 브랜드 룩. 스타일 캡슐

브랜드 룩을 작업 기억에 두지 않습니다. 세션이 끝나면 죽습니다. **스타일 캡슐**로 증류합니다. 재사용 블록 4~6줄.

```
palette:      <hex와 말로 된 색 이야기>
lighting:     <정확한 문장. 예 "warm window light, soft shadows">
finish:       <그레인, 질감, 렌더. 예 "analog film grain, matte">
composition:  <습관. 예 "centered subject, generous negative space">
tokens:       <시대, 장르 닻. 예 "8-bit", "Y2K editorial", "Kinfolk minimal">
never:        <피할 것, 그대로>
```

`./brand/creative-kit.md`가 있으면 거기서 가져옵니다. 없으면 사용자가 준 예시 자산에서 뽑습니다. 이미지를 읽고, 글자 그대로 보이는 것을 묘사하고, 쓰기 전에 캡슐을 확인합니다. 캡슐은 `./brand/creative-kit.md`의 `## Style Capsules`에, **캠페인이나 룩마다 이름**을 붙여 저장합니다 ("8bit-promo", "ugc-natural", "spring-editorial"). 스타일이 세션, 캠페인, 모델 교체를 넘기게.

장르 룩의 예시 캡슐 ("8bit-promo").

```
palette:      saturated primaries + warm sunset oranges, 16-bit console range
lighting:     flat 2D sprite shading, no realistic light sources
finish:       chunky visible pixels, dithered gradients
composition:  game-UI framing: HUD bars, menu boxes, overworld map views
tokens:       16-bit SNES RPG, classic JRPG overworld, pixel sprite
never:        smooth vector edges, photoreal textures, modern flat-design icons
```

캡슐이 패턴이고 장르는 변수입니다. 어떤 미학이든(클레이, 브루탈리스트 편집, 손그림, 포토리얼) 같은 여섯 줄입니다. 룩을 되게 한 것을 배워 그것을 잡습니다. 한 캠페인의 미학을 다음 브리프에 초대 없이 가져가지 않습니다.

장르 토큰은 형용사만보다, 시대 닻과 이름 있는 미학 닻(알아보는 게임, 영화, 편집 룩)이 있을 때 가장 세게 앉습니다. 캡슐이 실제 피사체를 다시 꾸밀 때, 피사체 참조 이미지가 캡슐과 함께 모든 호출에 탑니다. 캡슐이 세계를 정하고, 참조가 정체성을 잡습니다.

사용. 모든 생성이 활성 캡슐을 프롬프트 앞에 붙입니다. 같은 캡슐, 아무 모델. 사용자가 "우리 스타일로"라고 하면 캡슐이 그 뜻입니다. 캡슐이 아직 없으면 첫 산출물이 캡슐을 만드는 것입니다. 우회가 아닙니다.

## 4. 무드보드와 변형

방향 찾기는 주력 가격의 이미지 작업입니다.

1. **격자.** image-default(NB2)로 정말 다른 방향 4~8개, 각 한 장. 1K에서 합계 약 0.30~0.55달러(장당 0.067달러). 한 아이디어의 크롭 여덟 장이 아닙니다.
2. **선택.** 방향마다 분위기 한 줄과 위험을 달아 순위를 매겨 보여 줍니다. 사용자가 고르거나 섞습니다.
3. **잠금.** 승자를 스타일 캡슐(위)로 씁니다.
4. **승자만 변형.** 진 것은 변형하지 않습니다.

변형 규율. 한 번에 축 하나만 바꾸고, 어느 축을 움직였는지 적습니다.

- **시드를 잠그고 프롬프트 반복**(시드 고정, 프롬프트 절 하나 변경)은 문장이 한 일을 분리합니다. 룩을 다듬을 때.
- **프롬프트를 잠그고 시드 탐색**(프롬프트 고정, 시드를 굴림)은 정한 프롬프트에서 모델의 범위를 표본합니다. 방향 안에서 최선을 고를 때.

어느 모델이 시드를 존중하는지는 레지스트리 표. 시드가 없으면(NB2 계열) 합성으로 반복합니다. 이전 승자를 `image_input`으로 되돌립니다.

## 6. Replicate 밖의 전용 플랫폼

별도 구독과 API 키입니다. **반복 수요**일 때 갑니다. 단발이 아닙니다. 중간 지대가 이제 실재합니다. 두 벤더 모두 Replicate에 공식 모델을 올립니다(2026-11-13 확인). `elevenlabs/v3`, `elevenlabs/flash-v2.5`, `elevenlabs/music`, `elevenlabs/dubbing`. `heygen/avatar-v`, `heygen/lipsync-precision`, `heygen/lipsync-speed`, `heygen/video-translate`. 벤더 품질의 단발은 새 키가 필요 없습니다. 아직 명단에 없습니다. 여기서 미시험입니다. 브리프가 필요하면 레지스트리 방식(명단 줄, 절, 검증)으로 추가합니다.

목소리의 우리 선택은 ElevenLabs(무료 구간, 그다음 요금제)이므로, 반복 수요가 오면 아래 행이 먼저 가는 플랫폼입니다. 키가 없으면 Kling 립싱크의 내장 TTS나 아무 짧은 TTS가 대본 테스트를 덮습니다. 한국어 보이스가 필요하면 ElevenLabs에서 한국어 보이스를 고릅니다. 영어 기본 보이스를 한국어 음성인 것처럼 쓰지 않습니다.

| 플랫폼 | 갈 때 | Replicate 명단에 남을 때 |
|----------|-------------------|-----------------------------------|
| **ElevenLabs** (TTS, 목소리. Eleven v3는 2026-03-14 GA. 감정 방향의 인라인 오디오 태그, 70개 이상 언어. Flash v2.5는 실시간. Eleven Music은 스코어) | 목소리 품질이 제품일 때. 브랜드 보이스 복제, 에피소드·캠페인 일관성, 다국어 더빙, 말하는 사람 파이프라인의 미세한 속도 | 단발 내레이션이나 대본 반복 테스트는 lipsync-kling 내장 TTS나 짧은 TTS로 충분 |
