# 예시. 키워드 브리프에서 저장된 글까지

이것은 예시 흐름이지 끝난 조사가 아닙니다. 대괄호는 자리표시입니다. 발행하지 마세요. 1단계와 1.5단계가 실제로 라이브 증거를 모으기 전에는 글이 라이브 조사에 기대었다고 말하지 마세요. 아래 1단계와 1.5단계는 작업 노트입니다 (노트 파일로). 마지막 섹션만 고객이 보는 모양입니다.

## 시작 맥락

```text
타깃 키워드: "[타깃 키워드]"
검색 의도: [정보 / 상업 / 그 외]
글 유형: [가이드 / 비교 / 하는 법 / 그 외]
독자: [구체적인 독자]
고유 각도: [실제 경험, 원본 조사, 또는 특정 관점]
있는 실제 경험: [사용자가 받칠 수 있는 것]
```

예시 맥락. 한빛설비 (대구, 설비). 예시이며 실제 조사가 아닙니다.

```text
타깃 키워드: "대구 보일러 교체 비용"
검색 의도: 상업, 가격을 알아보는 중
글 유형: 가격 안내
독자: 보일러가 방금 고장난 대구 집주인
고유 각도: 최근 현장에서 본 실제 가격 구간과, 무엇을 올리거나 내리는지
있는 실제 경험: 사장님의 작업 기록 (사용자가 제공. 지어내지 않음)
```

기본 검색은 네이버 통합검색입니다. 구글은 구글 유입이 있을 때의 보조입니다.

## 1단계. 결과 현실

타깃 키워드와 쓸모 있는 변형을 돌리세요. 고른 결과마다 증거 꾸러미 하나. 아래는 작업 노트이지 고객 문장이 아니고, 실제 발견이 아니라 증거의 모양을 보여 줍니다.

```text
결과 현실: "[타깃 키워드]"

[URL]
- H2/H3 지도: [잡은 제목]
- 스키마: [찾은 유형]
- 보이는 날짜: [발행 / 수정]
- 답 블록: [페이지가 직접 답하는 것]
- 쓰는 증거: [귀속된 사실이나 예시]
- 공백: [빠지거나 틀리거나 말할 수 없는 것]

일반 결과 공백: [글이 다룰, 증거로 받친 공백]
```

라이브 수집이 불가능하면 분명히 말하세요. 대체는 출처와 가정에 일반 지식에 기대었고 발행 전에 확인하라고 적으며, 라이브 조사로 내놓지 않습니다.

## 1.5단계. AI 표면

타깃 질의의 답변 표면과 인용을 잡고, 쓸모 있는 대화형 말투와 비교하세요. 일반 결과 공백과 AI 인용 공백을 나누세요.

```text
AI SURFACE: "[타깃 키워드]"
네이버 브리핑/Cue: [있음 / 없음]
AIO present: [yes / no]
Cited: [도메인, 받친 주장, 왜 쓸모 있어 보이는지]
Variant phrasings cited: [관찰된 차이]
Citation gap: [아직 어떤 인용 출처도 주지 않는 것. 증거에 근거]
```

## 2단계. 브리프와 구조

증거를 브리프로 (작업 노트, 노트 파일과 함께 저장). 개요의 모든 약속에는 출처, 사용자가 준 사실, 또는 분명히 표시된 확인할 질문이 필요합니다.

```text
작업 제목: [직접 답과 구분되는 각도]
주요 키워드: [타깃 키워드]
보조 개념: [자연스럽게 속하는 말]
독자: [구체적인 독자]
고유 우위: [실제 경험이나 원본 증거]
답할 질문: [잡은 질문]
다룰 일반 결과 공백: [공백]
다룰 AI 인용 공백: [공백]
내부 링크: [사이트맵이나 로컬 자료의 실제 URL]
행동 유도: [맞는 다음 단계 하나. 전화, 카카오, 예약]
```

예시 가격 안내의 커버리지 맵 (예시, 실제 조사 아님).

```text
각도. 인용된 답은 전국 평균과 2년 전 비용 조사를 인용합니다. 한빛설비는 대구 고객의
보일러 교체에 실제로 든 비용을 자기 현장에서 낼 수 있습니다.
오늘 답이 어디서 오나. 전국 비용 사이트 둘과 카페 글 하나. 실제 지역 구간과
무엇을 움직이는지의 표가 들어 올려질 자리입니다.

질문이 하는 일별로
  예산 ("얼마를 예상하지")
    "대구 보일러 교체 비용"          서치어드바이저  표   공백. 답 불완전. 인용 출처는 전국 평균만
    "경동 대 콘덴싱 비용"            연관검색어      비교  가이드 둘이 잘 다룸
  수리할지 교체할지
    "12년 된 보일러 고칠 가치가 있나"  AI 질문       직접  공백. 관찰한 답 3개 중 3개에 브랜드 없음
  뜻밖의 비용
    "대구 보일러 교체 신고"           derived       직접  확인 안 함. 출처는 구청 안내

깊이 기준. 인용된 비용 페이지 둘이 스스로 서는 답 6개와 9개, 가격 표 하나씩, 약 1,400단어.
답과 표를 맞추세요. 단어는 따라옵니다.

주장 계약
  말해도 됨. "한빛설비는 대구 수성구, 달서구, 중구에서 경동과 콘덴싱 보일러를 교체합니다."
  말하면 안 됨. "대구에서 가장 믿을 수 있는 설비". 사장님이 문장으로 쓰지 않은 보장.
  먼저 확인. 가격 구간 (최근 12개월 작업 내보내기), "당일 교체" (얼마나 자주 사실인지).
열린 항목. 작업 내보내기. 수리 대 교체의 고객 이야기 하나, 허락과 함께.
표시·광고. "최저가", "1위"는 넣지 않음. 가격은 원. 구간은 장부 확인 전엔 자리표시.
```

개요 예시.

```text
H1: [답으로 향한 분명한 제목]
도입: [첫 단락의 직접 답]
H2: [독자의 첫 질문]
  답 블록: [스스로 서는 답]
  증거: [사용자가 준 사실 또는 귀속된 출처]
H2: [독자의 둘째 질문]
  답 블록: [스스로 서는 답]
  증거: [사용자가 준 사실 또는 귀속된 출처]
H2: [이 브랜드만 받칠 수 있는 고유 각도]
FAQ: [남은 관련 질문]
행동 유도: [전화, 카카오, 예약 중 하나]
```

## 3단계. 초안

브리프와 불러온 목소리로 쓰세요. 도입은 펼치기 전에 질의에 답합니다.

> [타깃 키워드]는 [평범한 답]입니다. [구체적인 독자]에게는 [사용자가 받친 결과] 때문에 중요합니다. 이 글은 [독자가 결정하거나 할 수 있는 것]을 설명합니다.

큰 제목마다 혼자 설 수 있는 답 먼저 블록을 쓰세요. 예시, 경험, 숫자는 사용자가 줬거나 출처가 받칠 때만. 증거를 만들어 내지 말고 자리표시를 두세요.

```text
[발행 전에 실제 예시 또는 귀속된 사실이 필요함.]
```

## 4단계. 사람 말투

`references/humanize.md`를 읽고, 초안이 실제 저자처럼 들리게 하세요. 범용 구를 빼고, 리듬을 바꾸고, 실제 경험만 더하세요. 답 블록은 직접적으로 두고, 주변 산문이 목소리를 가지게 하세요.

## 5단계. 맞추기

저장 전에 두 트랙을 조용히 확인하세요 (내부 패스, 고객에게 보여 주지 않음).

```text
전통 온페이지
- [주요 키워드가 필요한 자리에 자연스럽게]
- [제목이 의도와 잡은 질문에 맞음]
- [내부·외부 링크가 실제]

인용 형식
- [큰 섹션마다 스스로 서는 답 블록]
- [원본 사실마다 사용자 제공이거나 귀속]
- [이름이 일치하고 모호하지 않음]
- [신선함 주장이 확인됨]
- [가격·효과·순위 단정은 표시·광고 경고를 통과했거나 빠짐]
```

## 6단계. 스키마

끝난 글이 받치는 스키마만.

```yaml
schema:
  Article: [제목, 설명, 날짜, 본 페이지]
  Person: [실제 저자 이름과 프로필]
  Organization: [실제 발행자 이름, URL, 로고]
  FAQPage: [글에 실제 FAQ가 있을 때만]
```

## 저장 경로와 고객이 보는 것

실제 실행에서는 끝난 초안과 작업 노트를 여기 저장합니다.

```text
./campaigns/content/{keyword-slug}.md
./campaigns/content/{keyword-slug}.notes.md   # 1단계와 1.5단계 증거
./brand/assets.md                              # 저장한 자산 한 줄
```

채팅 산출은 통과한 일, 짧은 주석, 다음입니다. 데이터 태그, 문 점수, 도구 이름, 증거 꾸러미 없음 (예시).

```markdown
## SEO ARTICLE: 대구 보일러 교체 비용
2026-11-18 · 한빛설비 가격 안내 (예시 업체)

**글.** 자기 현장의 실제 지역 구간에 기댄 가격 안내. 지금 순위인 페이지는 전국 평균을 인용하므로, 날짜 있는 대구 구간과 무엇을 움직이는지가 우위입니다.

**발행 전에.**
- 가격 구간을 최근 12개월 작업과 맞추세요 (그때까지 자리표시).
- 수리 대 교체 고객 이야기 하나, 허락과 함께.
- 발행 때 IndexNow를 핑하고, robots.txt에 OAI-SearchBot이 허용되는지, 서치어드바이저에서 Yeti 수집이 되는지 확인하세요.
- "최저", "1위"는 넣지 않습니다. 표시·광고법상 거짓·과장과 부당 비교입니다.

**출처와 가정.**
- 2026-11-18에 전문으로 읽은 순위 페이지 6장과, 말투 3개의 AI 답으로 구성 (이 예시에서는 자리표시).
- 작업 데이터가 아직 없어 비용 섹션은 출처가 있는 구간을 인용하고 그렇게 표시.
- 확인 안 함. 제미나이. 작업 내보내기를 주시면 비용 섹션이 그 페이지의 유일한 지역 가격이 됩니다.

**저장한 파일.**
- ./campaigns/content/daegu-boiler-replacement-cost.md (새 파일)
- ./campaigns/content/daegu-boiler-replacement-cost.notes.md (새 파일)
- ./brand/assets.md (항목 1개 추가)

**다음.**
- /content-atomizer. 글에서 소셜 (약 10분)
- /ai-search. 비용 질문에서 AI가 누구를 부르는지 (약 20분)
```

이 예시는 실제 글이나 조사 결과를 만들지 않습니다.
