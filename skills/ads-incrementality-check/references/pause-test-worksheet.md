# 중지 시험 워크시트

파이썬이 없거나, 스프레드시트로 하거나, 방법을 다른 사람에게 넘길 때 읽어요. 스크립트(`scripts/call_log.py pause-test`)가 통화 CSV에서는 같은 숫자를 계산해요. 스마트콜과 카카오 문의는 스크립트가 가져오지 않아요. 아래 예시 숫자는 전부 예시예요.

## 1. 내보내기

| 출처 | 받을 것 | 어디서 |
|---|---|---|
| 전화 | 시험 전 60일 이상부터 끝까지, 모든 회선, 양방향 | 통신사 인터넷전화, 대표번호, 상담 프로그램의 통화 이력 CSV. 시각은 `YYYY-MM-DD HH:MM:SS`로 맞춰요 |
| 네이버 스마트콜 | 같은 날짜의 연결 수, 일 또는 주 | 스마트콜 또는 검색광고·플레이스 관리 화면. 내보내기가 없으면 숫자를 적어요 |
| 카카오 문의 | 같은 날짜의 1:1 문의·채널 채팅 | 카카오비즈니스 채널 관리자 |
| 광고 매체 | 그 캠페인의 일별 지출과 주장 전환 | 네이버 광고주센터, 구글 광고 일 단위, 메타 광고 관리자 일별 |
| 구글 비즈니스 프로필 | 구글 캠페인을 시험할 때만. 같은 날짜의 통화 | 프로필 실적. 내보내기가 없으면 적어요 |
| 작업 시스템 (선택) | 같은 날짜의 예약·작업 | 작업, 청구, CRM |

시스템마다 열 이름이 달라요. 통화마다 필요한 것. 시작 시각, 수신 또는 발신, 받음·부재중·음성사서함, 통화 시간, 고객 번호, 회선.

## 2. 정리

1. 수신만 남겨요.
2. 손님이 거는 회선만. 기사 직통과 내부 회선은 소음이에요.
3. 직원, 거래처, 알려진 스팸 목록의 번호를 빼요.
4. 받았고 30초 이상이면 "실제"로 표시해요.
5. 번호는 숫자만 남겨요. 스크립트는 끝 10자리를 키로 써요. `01012345678`과 `821012345678`은 같은 키가 돼요. 서울 02는 끝 10자리가 어긋날 수 있으니 다섯 줄을 눈으로 봐요.
6. 날짜(시각 제외), 요일, 구간(이전, 중지, 이후) 열을 더해요.
7. 시각이 UTC이면 먼저 한국 시간으로 바꿔요. 오프셋은 9시간이고 썸머타임은 없어요. 이미 한국 시각인 파일은 다시 밀지 않아요.

방향이 "수신/발신"인 파일은 스크립트에 넣기 전에 `inbound` / `outbound`로 바꿔요. "부재중", "음성사서함"은 영어 상태 단어를 보지 않으면 통화 시간으로만 나뉘어요.

## 3. 요약 표

구간마다 한 행. 하루 값은 구간의 일수로 나눈 것. 통화 0인 날도 포함.

| 구간 | 일수 | 수신/일 | 실제 통화/일 | 고유 발신/일 | 스마트콜 또는 카카오/일 | 주장 전환/일 |
|---|---|---|---|---|---|---|
| 이전 | 28 | 예시 14.0 | 예시 7.5 | 예시 9.0 | 예시 4.8 | 예시 4.0 |
| 중지 | 28 | | | | | 0 |
| 이후 | 28 | | | | | |

구글 캠페인 시험이면 스마트콜 칸을 비즈니스 프로필 통화 클릭으로 바꿔요. 고유 발신/일은 날짜별 서로 다른 번호를 센 뒤 구간 평균이에요.

## 4. 평소 흔들림

이전 구간을 온전한 주로 나눠요. 주마다 하루 실제 통화 평균. 가장 낮은 주와 가장 높은 주가 평소 흔들림이에요. 예. 하루 6.8, 7.9, 7.1, 8.2면 흔들림은 6.8에서 8.2. 중지 구간 7.4는 안이에요. 감지할 변화 없음. 중지 구간 5.1은 훨씬 밖이에요. 숫자는 예시예요.

## 5. 계절 보정 (기록이 작년까지 있을 때)

기대 중지 = 올해 이전 x (작년 중지 / 작년 이전).

예. 작년 같은 이전·중지 주가 하루 실제 통화 7.0과 7.7, 계절 상승 10%. 올해 이전이 7.5면 계절은 중지 동안 8.25를 예측해요. 중지 구간이 7.4면 캠페인이 하루 약 0.85통의 가치일 수 있어요. 하루 4통이라는 주장 옆에서는 여전히 작고, 행동 전에 평소 흔들림과 맞춰요. 예시예요.

## 6. 추가 통화 1건 비용

추가 통화 1건 비용 = 월 지출 / (하루 줄어든 실제 통화 x 30).

통화 가치 = 성사율 x 건당 평균 매출 총이익.

추가 통화 1건 비용이 통화 가치보다 낮고 오차 여유가 있으면 캠페인을 유지해요. 예. 월 200만 원이고 하루 0.85통이 줄면 통화당 약 7만 8천 원. 성사율 35%, 마진 40만 원이면 통화 가치는 14만 원이라, 0.85가 평소 흔들림 밖일 때 유지할 만해요. 예시예요.

## 7. 계획 템플릿 (끄기 전에 산출 파일로 복사)

```
캠페인: <이름>                   월 지출: <n>원
매체 주장: <날짜> 동안 전환 <n>건 = 하루 <n>건
지표: 수신/일, 실제 통화/일(받음, 30초 이상), 고유 발신/일,
      스마트콜 또는 카카오 문의/일, [신규 발신/일], [주당 작업]
포함 회선: <이름>            제외 번호: <건수> (직원, 거래처, 스팸)
이전: <날짜>~<날짜>   중지: <날짜>~<날짜>   이후: <날짜>~<날짜>
결정 규칙: 실제 통화/일이 <이전 최저 주>보다 낮고 고유 발신도
  줄면 재개. 둘 다 <낮음>~<높음> 안이면 중지 유지하고 예산을 <어디로>.
  그 외에는 더 긴 구간으로 다시.
사장님 승인: <이름>, <날짜>
```

## 8. 변형

- **브랜드 검색.** 브랜드 캠페인만 꺼요. 같은 통화에 더해, 네이버 서치어드바이저에서 상호 검색의 자연 클릭을 봐요. 구글을 쓰면 구글 서치 콘솔도. 상호로 자연 1위이고 경쟁사가 그 상호에 입찰하지 않으면, 브랜드 캠페인은 공짜로 올 클릭을 사는 경우가 많아요.
- **메타.** 캠페인을 끄고 같은 전화·폼 지표를 써요. 메타 기본 기여에는 조회 1일 창이 있어, 광고를 스쳐 보고 어차피 전화한 사람에게 성과를 줘요.
- **플레이스 광고.** 플레이스 광고만 끄고 파워링크는 유지하거나, 그 반대. 한 번에 둘을 끄면 무엇이 줄였는지 알 수 없어요. 분모는 스마트콜과 대표번호예요.
- **온라인.** 통화 대신 주문 시스템의 주문·가입. 신규와 재방문을 나누고, 하루 신규 주문을 세요.
